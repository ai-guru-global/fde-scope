# Security Policy

Please do not report vulnerabilities, leaked credentials, private customer
information, or other sensitive material through public issues.

For now, contact a Global FDE organization owner privately through GitHub. A
dedicated security address will be published when organization email
infrastructure is available.

When reporting a problem, include the affected URL or file, the potential
impact, and the minimum information needed to reproduce or verify it. Do not
include unrelated personal or confidential data.
