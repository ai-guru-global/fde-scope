## 1. 我们发的证书：是什么、不是什么

### 1.1 边界表

等级判定（A / B / C）的规则在 [`03`](03-评估体系与通关门禁.md) §6。本节只回答一件事：
**这张纸证明什么、不证明什么。**

| 维度 | ✅ 是 | ❌ 不是 |
|---|---|---|
| 性质 | 本训练营的**结业证书**（电子版），含 A / B / C 等级 | 不是职业资格证、不是职业技能等级证书、不是任何机构的"认证" |
| 证明内容 | 你**完成了哪些产出、通过了哪些门禁**（事实陈述，可回溯到原件） | 不证明"你能胜任 FDE 岗位"、不证明任何薪资水平 |
| 依据 | 门禁记录 + 评分量表（[`03`](03-评估体系与通关门禁.md) §4）+ 结营答辩记录 | 不做分数排名、不发"优秀率" |
| 署名 | 课程负责人 + 主讲讲师（电子签） | 不冒用任何机构或部委名义 |
| 备注栏 | **如实记录**补交 / 延期 / 豁免项（与门禁"留痕"原则一致，[`03`](03-评估体系与通关门禁.md) §6） | 不隐藏补交历史 |
| 归属 | 证书与作品集**归学员所有** | 对外展示需本人**书面授权**（[`03`](03-评估体系与通关门禁.md) §8） |

一句话：**这是一张"我做过什么"的证，不是一张"我行不行"的证。** 后者只有作品集和面试能回答。

### 1.2 编号规则与核验

| 项 | 规则 |
|---|---|
| 编号格式 | `<期次>-<等级>-<顺序号>`，例：`L1-2026Q4-B-007` |
| **一人一号** | 编号**终身唯一**。等级换发（C→B→A，[`14`](14-课后纵深与影子项目.md) §6.1）、信息纠错、到期续期，全部是**同一编号上的记录**，**永不新发编号** |
| 不编码个人信息 | 编号内不含姓名拼音、手机号、身份证号——编号泄露不构成 PII 泄露（[`03`](03-评估体系与通关门禁.md) §8） |
| 核验方式 | 通过课程官方联系渠道（与招生咨询同一入口）提交编号，课程方 **3 个工作日内**回执：等级 / 期次 / 状态 / 发证与到期日期。**当前为人工核验**；在线核验页见 §5 待办 |
| 核验**不**提供 | 不出具"推荐信""能力评价"式的额外背书——核验只复述**事实** |

> ⚠ 两件**别做**的事：① 把编号写进简历却不附核验入口说明（对方查不到，反而减分）；
> ② 自己编造/伪造编号格式——编号一旦开始被伪造，**所有人的证一起贬值**，这是公地悲剧。

### 1.3 有效期 2 年，以及"过期 ≠ 作废"

**有效期 2 年**，自发证日起算。为什么是 2 年而不是终身：FDE 的工具链迭代很快，
一份两年前的"能独立部署"记录，对雇主的参考价值本来就该衰减——这不是谦辞，是**对雇主的诚实**。
（同类证书的常见档位也是 2 年，见 [`13`](13-GTM页面与竞品对比.md) §4.2 的 ADaSci / GSDC 行。）

| 时间点 | 发生什么 |
|---|---|
| 到期前 60 天 | 向登记邮箱发**一次**到期提醒 + 复检包说明（只提醒一次，不追） |
| 到期 | 状态变为 **expired（已过期）**：核验如实回答"该编号的证书已于 `<日期>` 过期，最后等级为 B" |
| 复检 | 提交**复检包**：90 天纵深包更新（[`14`](14-课后纵深与影子项目.md) §2.1）+ 一件近期产出的自评 + 一段"工具链变了，我补了什么"。通过 → **同一编号**换发新有效期的证书（带复检日期） |
| 不续期 | 证书**不删除、不撤销**，只标 expired。**过期不等于作废**——把这两件事混为一谈，是在给自己制造未来的投诉 |

**唯一会"撤销"（revoked）** 的情形是 [`03`](03-评估体系与通关门禁.md) §7 / §8 的两条一票否决：
诚实标注判 0 未改、数据合规事故（真实客户名 / PII 进练习）。核验回执写"已撤销 + 原因**类别**"，
**不公开细节、不公开点名**——撤销针对的是**资格**，不是人。

### 1.4 申诉通道（三条，都留痕）

| 场景 | 走哪条 | 时限 |
|---|---|---|
| 觉得门禁 / 评分"判错了" | [`08`](08-运营手册.md) §10 的**申诉三步**：① 私聊班主任写清"哪一条 / 我认为应该是什么 / 证据"；② 24h 内由**未参与该次评分的人**复核原件；③ 结果书面回执。对 G8 结业门结果仍有异议 → 班主任升级讲师，**3 个工作日内终裁** | 24h 复核 / 3 工作日终裁 |
| 证书信息打错（姓名 / 等级 / 期次 / 编号） | **纠错通道**（与申诉分开）：提交后 7 个工作日内换发**同编号**证书。纠错不计入申诉次数、不影响任何评价 | 7 个工作日 |
| 涉及两条一票否决（诚实标注、数据合规） | **不走申诉豁免**（[`03`](03-评估体系与通关门禁.md) §8 原文），但**走复核**：复核只确认"事实认定是否有误"，**不改变豁免规则** | 同 G8 终裁 |

> 申诉与投诉的共同纪律（[`08`](08-运营手册.md) §10）：全程**书面留痕**、
> **不得**在公开群讨论具体内容、**不得**因申诉降低对学员的评价。

## 2. 第三方认证：三条可自行叠加的路径

> ⚠ **先读这三句**：① 本节是**信息汇总**，不是合作公告——我们与下列机构**没有合作关系、没有互认协议**
> （截至 2026-09-30）；② 它们认不认本课、我们认不认它们的证，**都不是本课能决定的**；
> ③ [`13`](13-GTM页面与竞品对比.md) §6 #2 的原话依然有效：**不能拿"认证"当卖点**。

### 2.1 三条路径

数字均引自 [`13`](13-GTM页面与竞品对比.md) §4.2 / §4.3，查证日 2026-09-30。

| 路径 | 主办 | 形态 | 费用 | 与我们的关系 | 适合谁 |
|---|---|---|---|---|---|
| **CFDE** | ADaSci（国际） | 30 小时 / 7 模块 / 自定进度 + **60 题监考** | US$164.99（官网；另有更高档 CFDE Pro，价格未显示） | 无合作，可叠加 | 想要一张**国际渠道可查**的认证、且能给英语监考考试留出时间的人 |
| **Certified FDE** | GSDC（国际） | 9 模块 / 40 题 / 90 分钟 / 65% 通过 | US$0–500（档位未取回全貌） | 无合作，可叠加 | 同上；偏好 **5 年有效期**的人 |
| **机构培训 + 官办证书** | 苏州瑞塔 / 三维天地 × 大连理工等 | 培训 4–5 天 + 发证 | ¥3,800–15,800 / 未取回 | **无合作**；这是"**再上一次课**"的路线 | 需要**体制内 / 国企**可识别背书的人 |

**读表纪律**：价格与规格以**主办方官网**为准——[`13`](13-GTM页面与竞品对比.md) §8 就记着两个源间冲突
（ADaSci 官网 $164.99 ↔ 媒体记 $249；GSDC 官网 9 模块 ↔ 第三方记 13 模块）。
本表**不替你做等价性判断**，也**不做换算**：比如"本课 22 小时 ≈ CFDE 30 小时的 73%"这种算法是伪科学——
**学时不是可比单位，考纲内容才是**。

### 2.2 叠加的实操顺序（建议，不是规定）

1. **先结课、先攒作品集。** 认证是锦上添花，作品集才是你的证据（[`README`](README.md) §3 的八件产出）。
2. **再挑一门考试。** 复习素材就是你的 8 件产出：它与 CFDE 的 7 个模块有**大面积重叠**——
   但**没有官方对照表**，重叠到什么程度**以你自己读考纲为准**。本课**不出**"考点对照表"（出了就是代人言）。
3. **简历 / 作品集怎么并列写**（措辞纪律，与 [`10`](10-变现路径与结营包.md) §8 同源）：

```
✅ FDE 训练营结业（A 级，8 件产出见作品集索引页）
✅ ADaSci Certified Forward Deployed Engineer (CFDE)，2026
❌ 工信部认证 FDE —— 证不是从那个渠道拿的，就是虚假陈述
❌ 学完本课可直接通过 CFDE 考试 —— 我们没考过，这句话没有任何依据
```

### 2.3 我们不做的三件事

1. **不办"包过班"、不代报名、不收返佣**——若未来出现合作，会在本节**明示**合作范围与是否收费。
2. **不声称"上完本课即可通过 XX 考试"。**
3. **不用第三方的 logo / 证书样张做招生页**（未经授权使用他人标识是另一类合规问题，[`08`](08-运营手册.md) §11）。

## 3. 结果度量：把"设计基线"变成"可采集"

### 3.1 问题出在哪

[`09`](09-运营指标与复盘.md) §3 的合格线（完课率 ≥ 70%、作品集完整率 ≥ 60%、NPS ≥ 40）是**设计推演的基线，不是实测**——
这一条我们自己写过（[`13`](13-GTM页面与竞品对比.md) §6 #5）。真正的问题不是"数字难看"，
而是"**从没定义过怎么采**"：不定采集口径，第一期跑完只会得到一堆互相矛盾的数。

所以本节做三件事：**定五项指标 → 定发布门槛 → 定填表规则**。

### 3.2 五项对外指标（口径先写死，事后不许改）

| # | 指标 | 分子 ÷ 分母 | 采集时点 | 数据来源 | 对外发布门槛 |
|---|---|---|---|---|---|
| 1 | **作品集完整率**（北极星） | 8 件齐全人数 ÷ **实际开课人数** | G8 结营日 | 门禁台账（[`08`](08-运营手册.md) §4） | n ≥ 20 |
| 2 | 完课率 | G1–G7 通过 ≥ 6 关人数 ÷ 实际开课人数 | G8 | 门禁台账 | n ≥ 20 |
| 3 | NPS | （推荐者 − 贬损者）÷ 回收份数 | 结营后 48h | 结营问卷 | n ≥ 20 **且**回收率 ≥ 60% |
| 4 | D+7 变现动作率 | 完成 ≥ 1 个变现动作人数 ÷ 结业人数 | D+7 | D+7 回访（[`04`](04-交付实施手册.md) §5） | n ≥ 20 |
| 5 | D+90「用上了」率 | 选"用在工作 / 求职 / 接单"人数 ÷ **有效回收**人数 | D+90 ± 7 天 | [`09`](09-运营指标与复盘.md) §11 三题问卷 | n ≥ 20 **且**回收率 ≥ 40% |

**分母定义**：「实际开课人数」= D1 实际出席（≥ 一半时长）人数，与 [`09`](09-运营指标与复盘.md) §2 的漏斗口径一致。
**任何一格比率都必须能回答"除以谁、什么时候采的"**（[`09`](09-运营指标与复盘.md) §9 的口径纪律）。

### 3.3 对外发布四条纪律

1. **n < 20 只做定性，不做百分比。** 小样本比率毫无意义（[`09`](09-运营指标与复盘.md) §11 对内的线是 8 人；
   对外取更严的 20——因为对外引用**没有机会解释口径**）。
2. **永远带分母与样本量**：
   ✅「第 1 期：作品集完整率 63%（19 / 30，实际开课 30 人）」
   ❌「作品集完整率 63%」
3. **不挑期次。** 有 ≥ 2 期数据后，对外必须**连续展示**（含表现差的那期）；只发最好的一期 = 樱桃采摘（[`09`](09-运营指标与复盘.md) §10）。
4. **差评与掉队同等发布。** 每期对外页同时写明"这期没过哪条硬线"——与 [`09`](09-运营指标与复盘.md) §6 期报同口径，
   不许对外只留半张脸。

### 3.4 反模式（本节自己不许犯）

| 反模式 | 为什么不行 |
|---|---|
| 拿"报名人数 / 群人数"当成绩 | 免费留资谁都能冲量（[`09`](09-运营指标与复盘.md) §10） |
| 把 D+90「用上了」换算成"就业率 / 涨薪率 / 平均薪资" | 问卷里**没有**这些字段，换算即编造（[`09`](09-运营指标与复盘.md) §11） |
| 用"学员反馈热烈" | 无法证伪的形容词（[`09`](09-运营指标与复盘.md) §10） |
| 只摘一个好看的数字做海报 | 见 §3.3 第 2、3 条 |
| 把分母从"实际开课人数"悄悄换成"交作业的人数" | 分母变小、数字变好看，属于**改口径刷分**（[`09`](09-运营指标与复盘.md) §9 明令禁止） |

### 4.4 采集 schema：每一格到底从哪个字段来

> §4.1 的「填表规则」第 2 条要求每格能回答"**分母是谁、什么时候采的、谁采的**"。
> 本节把这句话兑现到**工具这一侧的字段名与文件路径**上——不写清这一层，第一期结束时能拿到的只有截图和记忆。
> 下面所有"机器侧"条目都是 **2026-10-08 本机实测**：`FDE_SCOPE_HOME` 指向临时目录跑，不碰真实数据目录。
> 档位沿用 [`24`](24-开源对标与来源清单.md) §0.1 的五档（工具实测 > 代码原文 > 搜索摘要 > 教案原文 > 未取回，缺口记 **GAP**）；
> **本节基准日 2026-10-08**，与本章开头"0 期"那条 **2026-09-30** 基线分开记，两个日期不许混用
> （[`13`](13-GTM页面与竞品对比.md) §8 同规）。

#### 4.4.1 五项对外指标 → 字段级来路

| # | 指标（§3.2） | 分子取自哪个字段 | 原始工件（实测路径） | 采集动作与归档责任 | 档位 |
|---|---|---|---|---|---|
| 1 | 作品集完整率 | `labs[].ok == true` 的天数（满 8 天） | `course check all --json` 的 **stdout**，实测顶层 `{passed: 81, failed: 10, manual: 9, ok: false}` | 学员自己跑、**把 JSON 原件交上来**——`--json` 只打印不落盘，归档责任在运营侧 | 机器侧 = 工具实测；出席分母 = 教案原文（`08` §4 / `09` §2），数值**未取回** |
| 2 | 完课率 | `gate_records` 里 `passed == true` 的 slug 数（≥ 6） | `<root>/.fde_scope/engagements/<eid>.json`；单条记录实测字段 `{slug, passed, blockers[], warnings[], notes[], checked_at}` | 判分即写入：`gate check`（退出码 0 = 通过、1 = 被拦，实测）或 console 的 gate 按钮 | 工具实测 |
| 3 | NPS / 回收率 | （推荐者 − 贬损者）÷ 回收份数 | **无工件**：问卷在群里 / 表单里 | 班主任导出原始打分列表，**同时存"回收 / 应回收"两个数**（§3.2 的回收率 ≥ 60% 门槛要用后者） | 教案原文（`09` §3 / §9）；数值**未取回** |
| 4 | D+7 变现动作率 | 完成 ≥ 1 个变现动作的人数 | **无工件**：回访记录（`04` §5） | 回访表逐人打勾，动作名**照 `04` §5 的枚举写**，不自造类别 | 教案原文；数值**未取回** |
| 5 | D+90「用上了」率 | 三题问卷第 1 题选"用在工作 / 求职 / 接单"的人数 ÷ 有效回收 | **无工件**：`09` §11 的三题问卷 | D+90 ± 7 天群发一次 + 未回者单聊一次，**不追问第二次**（`09` §11 原文） | 教案原文；数值**未取回** |

> 只有第 1、2 行是**工具能自证**的——这正是 §5 待办 #1 说"首批数据"时必须连 JSON 原件一起归档的原因。
> 第 3–5 行永远靠人：**人是口径的一部分，不是口径的例外**。

#### 4.4.2 §4.3 四条内观察项 → 通道到底有没有

| 观察项 | 机器侧能不能取 | 实测依据（2026-10-08） | 第一期兜底采法 | 档位 |
|---|---|---|---|---|
| 被拦最多的 gate（按 slug） | **能，但只留最后一次** | `gate_records` 以 slug 为键，同一 gate 复判**覆盖**前一次（实测：连续判分后键里仍只有那一个 slug） | 每判一次就归档一份 JSON，别指望回头查 | 工具实测 |
| 「被拦 → 补交 → 通过」平均轮次 | **⛔ 现无通道** | 覆盖 + 两个不留痕：`journal` 只收 `research / implementation / optimization` 三类现场记录（`JournalEntry` 字段实测为 `id, ts, kind, note, skill_id`），**不含 gate 事件**；CLI 侧 `gate check` / `engage advance` **不写** `audit.jsonl`（实测：跑完这两条命令后 `<root>/.fde_scope/audit.jsonl` 不存在） | 判分统一走 console：`POST /api/engagements/{eid}/gate/{slug}` 每次**追加**一条 `engagement.gate_evaluate`（detail 实测含 `engagement_id, gate, passed`，可选 `operator`）→ 轮次 = 按 eid+slug 数行 | 工具实测 + 代码原文 |
| 申诉件数与改判率 | **⛔ 无工件** | §1.4 三条通道都是人工留痕（邮件 / 群 / 表单），产品里没有 appeals 对象 | 自设 `appeals.tsv`：`case_id / eid / gate / 受理人 / 结论（维持·改判）/ 耗时（自然日）`；缺列如实写"未记录" | 教案原文 + **GAP**（表结构本课自设） |
| 证书纠错件数与耗时 | **⛔ 无工件** | 登记面实测：`<root>/.fde_scope/showcase/<entry_id>/entry.json` 字段为 `entry_id, alias, cohort, level, cert_no, portfolio, version, created_at, updated_at`；`index.json` 只带前 6 项 + `updated_at`；**没有"纠错"字段**；`version` 有 `touch()` 方法（`fde_scope/course/showcase.py:198`）但**当前无调用点**，API 面只有 register / list / audit 三个路由——**改不了也删不了**，纠错只能重新登记一条新 entry 或走线下 | 另建 `cert_fixes.tsv`：`cert_no / 原值 / 新值 / 依据 / 处理人 / 耗时`；§5 待办 #3 的核验页建成后再谈线上化 | 代码原文 + **GAP** |

#### 4.4.3 三条 schema 纪律（把 §3.2「口径先写死」落到字段级）

1. **每格三件套不可省**：分母定义 / 采集时刻（ISO-8601 UTC，与 `audit.jsonl` 的 `ts` 同格式）/ 采集人。
   ⚠ 实测：`audit.jsonl` 的 `actor` 恒为默认值 `local`（`fde_scope/audit.py:33` 的 `log_event(action, actor="local", ...)`），
   所以**"谁采的"不会自动出现**——console 判分时必须把班主任填进 `operator` 表单字段，不填就永久缺失。
2. **只从原件重算，不从截图反推**：JSON 原件按 `期次 / 学员 / 日期` 归档；期报里每个比率都应能从归档原件跑出来。
   这也是 §4.1「填表规则」第 1 条"期报冻结后才能填"的可执行版本。
3. **复现命令写进期报附录**（不进对外页）：lab 侧 `course check all --json` 实测全程 ≈ 7 s、任一条红则退出码 1，
   **冷跑必红是设计**——命令自己的帮助文案写着"冷跑会在「写作项」上红——starter 里 TODO 还在就是没写完，这是设计"
   （实测自 `course check --help`，档位 = 代码原文），不是课程有 bug。
   ⚠ 这条别出现在招生页：红着的样子会被读成故障。

> **本节不产生任何数字**，§4.1 的表照旧整张留空。
> schema 的全部作用是：第一期填进去的每个数**都能被追问到底**——追问不倒的数才配对外（§3.3），
> 追问不倒这件事本身就是公信力（[`24`](24-开源对标与来源清单.md) §8 的引用纪律用到自己身上）。

## 7. 反模式：自毁公信力的六种写法

1. **给「待补」填数字。** 一个假数字毁掉的是整张表——包括那些真的数字。
2. **小样本海报。** 把 n = 5 的那期做成宣传图，等于承认其他期不敢发。
3. **换算就业率 / 涨薪率。** 问卷没问的问题，答案从哪来？
4. **拿第三方认证做课程卖点。** 那是人家的证；用人家的证给自己贴金，两头都不占理。
5. **只发最好的一期。** 见 §3.3 第 3 条。
6. **把"过期"说成"作废"。** 今天混淆这两个概念，明天就会混淆"撤销"和"没通过"。
