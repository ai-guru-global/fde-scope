# 09 · 运营指标与复盘

> 本文件回答两个问题：**这期办得好不好，拿什么数字说话？办完之后怎么改进，改进有没有落地？**
> 操作流程见 [`08-运营手册.md`](08-运营手册.md)｜教学复盘视角见 [`05-讲师手册.md`](05-讲师手册.md) 第 9 节。

---

## 1. 北极星指标

**北极星 = 作品集完整率**（8 件产出齐全的学员数 ÷ 实际开课人数）

为什么不是完课率？因为完课率可以被"降低标准"刷高——少判几道门禁、多放几个补交，数字立刻好看。
而**作品集才是这门课的承诺物**：招生海报上写的是"8 件可展示产出"，兑现或没兑现，只看这一件事。

| 层 | 指标 | 回答的问题 |
|---|---|---|
| **北极星** | 作品集完整率 | 承诺兑现了吗？ |
| 辅助 | 变现动作率（D+7） | 学员真的用起来了吗？ |
| 漏斗 | 7 级转化（见第 2 节） | 哪一段在漏水？ |
| 健康度 | 每日看板（见第 4 节） | 今天要不要干预？ |

**一个视角提醒**：复训率与转介绍率是滞后指标，第一期不要拿它对标——首期先攒基线。

## 2. 转化漏斗（7 级）

```
曝光 → 报名留资 → 缴费确认 → G0 入学门 → D1 开课 → G1–G7 逐关 → G8 结业 → D+7 变现动作
```

| 级 | 定义（口径） | 采集点 | 首期基线 |
|---|---|---|---|
| 曝光 | 招生内容触达人次（各渠道去重后估算） | 运营台账 | 首期只记录，不设目标 |
| 报名留资 | 填写报名表人数 | 报名表单 | —— |
| 缴费确认 | 完成缴费的人数 | 收款记录 | ≥ 留资的 40% |
| G0 入学门 | 环境自检 + 契约 + 雷达三项完毕 | `06` §2 提交记录 | ≥ 缴费的 85% |
| D1 开课 | 实际出席 D1 直播（≥ 一半时长） | 直播记录 | = 缴费人数（开营前流失在此暴露） |
| G1–G7 | 每关通过人数（分关记录，不合并） | 门禁台账（`08` §4） | 逐关见第 4 节预警线 |
| G8 结业 | 拿到结业证书人数 | 答辩记录（`03` §5） | ≥ D1 的 70% |
| D+7 变现动作 | 完成至少 1 个变现动作（更新简历/内部汇报/投递/接单咨询） | D+7 回访（`04` §5） | ≥ 结业者的 60% |

**漏斗纪律**：

1. **分关记录，不合并。** "G1–G7 通过"这种合并口径会掩盖"卡在第 4 关"的真实问题。
2. **首期基线用实测校准。** 上表的建议值来自设计推演，不是行业数据——第一期跑完用实测覆盖它，
   不要拿"行业均值"假装权威（与课程"诚实标注"原则一致）。
3. **每级都记分母。** 任何比率都必须能回答"除以谁"。

## 3. 每期体检表（合格线）

一期训练营是否"交付合格"，与 [`04-交付实施手册.md`](04-交付实施手册.md) 第 8 节同源，此处为运营侧的执行口径：

| # | 指标 | 合格线 | 判定 | 未达时的第一动作 |
|---|---|---|---|---|
| 1 | 完课率（G1–G7 通过 ≥6 关） | ≥ 70% | 硬线 | 掉队归因（第 5 节）写入期报 |
| 2 | 作品集完整率（北极星） | ≥ 60% | 硬线 | 检查是否为"最后两关集中掉队"，下期重排时间盒 |
| 3 | NPS | ≥ 40 | 硬线 | 低于 0 的差评逐条读，进期报原声节 |
| 4 | 数据合规事故 | = 0 | **一票否决** | 立即按 `08` §11 处置，当期不得宣传 |
| 5 | 掉队复活率（进干预后回到 G 链） | 记录观察 | 参考 | 复盘三级干预哪一级失效 |
| 6 | 门禁平均补交率 | 记录观察 | 参考 | 补交率过高说明当日时间盒太紧 |

> **一票否决说明**：第 4 项不为 0 时，前 3 项再好看也不构成"合格交付"——
> 这与仓库 `Engagement.advance()` 的 blocker 语义一致：**硬拦项不通过，其余分数不生效。**

## 4. 每日健康度看板与预警线

### 4.1 看板字段（每日 22:00 汇总时填写，`08` §4）

| 字段 | 口径 | 一眼看什么 |
|---|---|---|
| 当日提交率 | 当日产出提交人数 ÷ 在线人数 | 掉了没有 |
| 当日门禁通过率 | 通过人数 ÷ 提交人数 | 是"没交"还是"交了不过" |
| 答疑积压 | 19:00–20:00 窗口未闭环问题数 | 助教够不够 |
| 有效互助次数 | 帮同学解决问题且被确认的次数 | 社群是否在互助而非围观 |
| 掉队预警名单 | 触发预警线的人（见 4.2） | 今晚要不要私聊 |
| 一句话异常 | 今日最出乎意料的一件事 | 期报素材 |

> **掉队预警名单**同时抄送讲师，进入 `09` 掉队档（第 5 节）。

### 4.2 预警线 → 联动 `08` 三级干预

| 信号 | 黄线（提醒） | 红线（立即动作） | 联动 |
|---|---|---|---|
| 连续未打卡 | 1 天 | 2 天 | 红线自动进三级干预**第一级**（`08` §7） |
| 当日提交率 | < 70% | < 50% | 红线：班主任当晚全员私聊排查 |
| 某关门禁通过率 | < 60% | < 40% | 红线：次日直播加 10 min 回炉重讲该关考点 |
| 答疑积压 | > 5 人排队 | 响应 > 2h | 红线：启用第二答疑窗口（助教加班排班） |
| 有效互助次数 | 连续 2 天 < 3 次 | 连续 3 天 < 3 次 | 红线：运营发起话题引导（`08` §5） |
| NPS 中期快评 | ≤ 0 | ≤ −20 | 红线：讲师 48h 内找 3 名差评学员 1v1 面谈 |

**原则**：预警线只用来**触发动作**，不用来考核助教。指标一旦变成 KPI，就会被优化成数字游戏
（比如助教抢答简单问题刷"互助次数"）——这是运营自己的反模式。

## 5. 掉队档（本期学员异常档案）

由 `08` §7 的三级干预结果汇入，一人一行，逐期滚动。

| 字段 | 说明 |
|---|---|
| 姓名 / 分班 | 用于联系与面谈 |
| 触发日 / 触发级 | 哪天触发、落到三级干预的第几级 |
| 干预动作 | 实际做了什么（私聊 / 1v1 / Mini 版产出 / 谈话） |
| 结果 | **复活**（回到 G 链）/ **延期**（转下期）/ **退款** / **失联** |
| 流失原因分类 | 见下方枚举，必填（失联者由班主任推测并标注"推测"） |
| 备注 | 面谈原话摘录（1–2 句），用于期报归因 |

**流失原因枚举**（统计时只在这 6 类里选，防止"原因：忙"淹没一切）：
`时间冲突` / `难度超预期` / `环境受阻（装不上）` / `健康或家庭` / `岗位或工作变动` / `其他`。

> **铁律**：掉队档是内部档案，只在讲师与运营之间流转；任何对外材料不得出现学员姓名
> （与 `03` 第 8 节的留档规则一致）。

## 7. 改进项闭环追踪表（长期滚动）

> 规则来自 [`04-交付实施手册.md`](04-交付实施手册.md) 第 7 节：
> **期报中的每个"改进项"必须在下期开营前落实或明确否决。**
> 本表就是那句"闭环记录在 `09`"的落地载体；`02` 文档头提到的"期报复盘闭环"也指这里。

| 编号 | 来源期次 | 改进项 | 类型 | 负责人 | 截止 | 状态 | 验证方式 / 否决理由 |
|---|---|---|---|---|---|---|---|
| 001 | 第 1 期 | 例：D4 时间盒 35 min 不够，多数人话术没写完 | 教材 | 教研 | 第 2 期开营前 | **已落实** | D4 时间盒改 45 min，`02` 已更新 |
| 002 | 第 1 期 | 例：改用某新工具替代现有演示 | 交付 | 讲师 | 第 3 期开营前 | **已否决** | 学员环境安装成本高，与"零门槛"原则冲突 |

**状态只有四种**：`待办` / `进行中` / `已落实` / `已否决`。
**两条硬规矩**：

1. **否决必须写理由**——"已否决"要能回答"为什么不做比做了好"。
2. **跨期滚动，不允许无声消失**——上期"待办"在本期开营日仍无进展的，在期报第 6 节置顶标红。

## 8. D+30 期报复盘会

**参加**：课程负责人、讲师、助教代表、运营。**时长**：90 min。**输入**：期报 + 闭环追踪表。

| 时段 | 议程 | 产出 |
|---|---|---|
| 20 min | 数据回放：漏斗 + 4 条硬线 + 掉队档 | 全员对事实达成一致（不解释，先看数） |
| 20 min | 掉队归因：流失原因 Top2 逐条过 | 归因结论（区分"课程问题"与"个体原因"） |
| 15 min | 学员原声：差评逐条读（匿名） | 至少 1 条转化为改进项 |
| 25 min | 闭环追踪表逐行核对 | 更新状态；新增改进项定人定截止 |
| 10 min | 下期开营准备：硬线不达标的补救动作 | 下期开营前必办清单（≤3 件） |

**会前必做**：上一期标记"已落实"的改进项，**抽查 1 条验证真伪**（比如改过的时间盒，
直接翻 `02` 对照）——闭环不是打勾，是验证。这与课程讲给学员的"门禁思维"完全同构：
**清单会烂，验证不会。**

## 9. 数据口径与隐私

| 项 | 规则 |
|---|---|
| 采集时点 | 看板每日 22:00；漏斗在结营日冻结；D+7 变现动作在回访时采集 |
| 分母 | 所有比率的分母必须写进口径说明（第 2、4 节表格里已固化） |
| NPS 回收率 | < 60% 时，NPS 数值标注"低回收率，仅供参考"，不与往期直接比较 |
| 匿名化 | 期报中的学员原声一律去名；掉队档仅讲师/运营可见（`03` §8） |
| 对外使用 | 期报数据对外（招生、宣传）引用时，必须同时给出分母与样本量，禁止只摘"完课率 92%"式的裸数字 |
| 上报纪律 | **不修饰**：掉队、退款、差评如实上报。运营不得为达标而调整门禁判定——门禁归讲师，指标归运营，这两件事永不互相将就 |

## 10. 反模式：会骗人的指标

| 虚荣指标（别用） | 为什么骗人 | 替代指标 |
|---|---|---|
| 报名人数 | 免费留资谁都能冲量 | 缴费确认数 + 开课率 |
| 直播在线时长 | 挂机也算 | 当日提交率 + 门禁通过率 |
| 群消息数 | 灌水也算 | 有效互助次数（被确认的） |
| 完课率（单独用） | 可被放宽判定刷高 | 作品集完整率（北极星） |
| 满意度打分 | 不看回收率没有意义 | NPS + 回收率 |
| 平均分 | 掩盖尾部 | 分数分布 + 最低分那件产出 |
| "学员反馈热烈" | 无法证伪的形容词 | 差评原文 + 改进项闭环率 |

> 这张表的反面，就是课程教给学员的同一件事：**证据 > 描述**。
> 运营用虚荣指标自我麻醉，和 FDE 用策展数据演 Demo，是同一种债务。

## 11. D+90 长期跟踪（轻量版，3 个问题）

> **为什么要有**：本课对外的一切说法都卡在"**不承诺就业/收入**"上（`10` §8）。
> 但"不承诺"不等于"不关心"——结营 3 个月后学员到底用没用上，是课程唯一能拿出的**长期证据**。
> 不做长期跟踪，课程就只能永远说"我们教得很好"，而这恰恰是本课批判的"无法证伪的形容词"（第 10 节）。

**什么时候发**：结营后第 90 天（±7 天），群内一次群发 + 未回者班主任单聊一次，**不追问第二次**。

**问卷（就 3 题，30 秒可答完）**：

```
【<期次> 校友 3 个月回访 · 3 个问题】
1. 这 3 个月里，你有没有用过课上的东西？（单选）
   □ 用在工作里了   □ 用在求职/面试里了   □ 用在接单/副业里了
   □ 只自己练过，还没用出去   □ 完全没用上
2. 用得最多的是哪一件产出？（单选，与 `README` §3 八件同源）
   □ 委托单  □ 数据体检  □ 语料报告  □ 原型与评估
   □ Runbook/SLO  □ 交接包  □ 技能卡  □ 作品集包装
3. 如果只能改课程的一件事，你改什么？（一句话，可留空）
```

**回收与使用纪律**：

| 项 | 规则 |
|---|---|
| 目标回收率 | ≥ 40% 即可用；< 40% 标注"低回收率，仅供参考"（同第 9 节） |
| 样本量纪律 | 回收 < 8 人时**只做定性参考，不做百分比对外引用**——小样本的比率毫无意义 |
| 对外引用 | 只能引用"**具体某人做了什么**"（匿名化成"某期学员 A 在 <行业> 把语料报告用在了 <场景>"），**禁止**换算成"就业率/涨薪率/接单率" |
| 反向用途 | 选"完全没用上"的人，**单独私聊 15 分钟**问"卡在哪"——这是课程最有价值的一份输入，进期报改进项 |
| 隐私 | 问卷匿名；若需署名引用，取得**书面授权**（`03` §8） |
| 归档 | 结果进本期期报附件（`09` §6）；跨期汇总看"哪件产出被用得最多"（指导课程重心调整） |

**与北极星的关系**：北极星是"作品集完整率"（第 1 节），衡量**交付质量**；
D+90 跟踪衡量**交付之后的实际使用**。两者一起，才凑齐了"教得成 → 用得上"的完整证据链。
**若连续两期 D+90"完全没用上" ≥ 30%**：这不是运营问题，是**课程设计问题**——
按 [`08`](08-运营手册.md) §1 的角色链路升级：**运营 → 课程负责人 → 讲师**，在本节 §8 复盘会上列为专项议题；
相关结论写回 `02`（时间盒）/ `05`（带教）/ `07`（案例）的对应章节，并在期报第 6 节留痕。
