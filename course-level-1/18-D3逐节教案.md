## S1 · 回炉（0–10 min · 10 min）

**本节定位**：10 分钟干三件事——交出 D2 的账（门禁榜 + 1 优 1 劣），然后用一次**全班预注册**制造今天的认知冲突。**不讲课，只讲评 + 提问。**

**一句话目标**（开场念）："昨天你签了字。今天你要拿出证据，证明你签的字站得住——或者，当场发现自己签错了。"

### 分钟级时间盒

| 分钟 | 动作 | 目的 |
|---|---|---|
| 0–3 | **G2 门禁榜**（3 个数字）+ 补交规则复述 | 让"过没过"变成公开事实 |
| 3–8 | **1 优 1 劣讲评**（都不点名） | 让"好长什么样"可复制，让"坑"提前暴露 |
| 8–10 | **先猜后看预注册**：群里打 3 个数字 | 制造今天上午的认知冲突 |

### 讲稿要点

**① G2 门禁榜（0–3 min）——只念三个数字**

投屏一张表，不要念名单（念名字会把讲评变成社死现场）：

| 指标 | 数字（讲师课前填） | 念法 |
|---|---|---|
| 提交率 | `__ / __` | "今天有 N 位同学没有交——不是骂人，是提醒：**门禁是逐关的，缺一关后面全堵**" |
| G2 一次通过率 | `__%` | "接近一半的人第一次没过。**这是正常的**，D2 的门禁就是这么设计的" |
| 被拦最多的一条 blocker | 通常是 ② **≥2 位发起人** | "第二名被拦的是 ③ 放弃标准缺失——**放弃标准是 warning，为什么会拦？** 因为它缺了就没人拦 Scope Creep（[`12`](12-附录-术语表与模板库.md) §1.6 第 1 条）" |

> ⚠️ 讲师注意：**补交规则要在这一分钟念完整**——24 小时内补交 = **正常放行（标注"补交通过"）**；超过 24 小时 = **延期通过**，**作品集等级最高 B**（[`03`](03-评估体系与通关门禁.md) §3）。D2 已有未交者，今天再念一遍，不针对个人。

**② 1 优 1 劣讲评（3–8 min）——两份都匿名，都念原文**

**优的那份**（从提交中挑，隐去姓名与公司名），念完立刻**指认三个动作**——不要只说"写得好"：

> "第一，成功标准里**验收主体是客户**：'门店催单率下降 30%（周报口径，门店运营可自查）'——注意括号里那半句，那才是真功夫。
> 第二，干系人地图上有**第二发起人**，而且标注了'她怕什么'。
> 第三，放弃标准写成**条件句**：'若 30 天内拿不到历史工单导出权限，建议暂停并重谈范围'。
> 这三条，就是 G2 的 ②③④ 三条。**你们抄的不是这份文档，是这三条的动作。**"

**劣的那份**（典型错误，同样匿名），念完**把错误落到门禁条款上**：

> "这份的六个成功标准里，有四条是形容词——'提升客户体验''提高响应速度'。
> 我不骂它。我只问一句：**这条标准，客户自己能验收吗？** 客户验收不了的标准，
> 到了 D7 验收清单那一栏，就是一行**空格**（[`12`](12-附录-术语表与模板库.md) §2.11）。
> 还有，干系人图上只有一个人。昨天我说的那三个字，今天再写一遍——**死亡风险**。"

> ⚠️ 讲师注意：**1 优 1 劣的两种错法必须是当天最高频的两种**（见 [`09`](09-运营指标与复盘.md) 的作业抽样）。不要挑"离谱的错"逗笑全场——**要挑"大多数人都犯的错"**，才有纠偏价值。

**③ 先猜后看预注册（8–10 min）——今天最重要的一分钟**

投屏这三个问题，**让全体在群里打数字**（不是打"是/否"）：

```
① 这份工单数据，四列里会被工具标出 PII 的有几列？   猜：__ 列
② 20 条文本里，藏着能定位到真人的信息的有几条？     猜：__ 条
③ 9 个类别里，有几类"够用"（按每类 ≥100 条真实样本）？ 猜：__ 类
```

**不许现在解释"为什么是这些数字"。** 让学员猜完、群里刷完屏，你再收口：

> "记住你打的那三个数。**25 分钟后我们一条条对**。
> 我不提前说答案——因为在真实项目里，也没有人提前告诉你答案。
> 你能不能在这个行业里活下去，取决于一件事：**你敢不敢先看，再下结论**。"

**这就是今天全天唯一的动作：先看，再装。**（[`05`](05-讲师手册.md) §4 D3 第 1 条）

### 投屏·板书

- 左：**G2 门禁榜**（三个数字，不出现人名）
- 中：**优的那份的三个动作**（验收主体是客户 / 第二发起人 / 放弃标准是条件句）
- 右：**三个猜测问题**（群里刷数字，投屏只留问题）
- 白板角落：**停车位**（今天所有跑题问题记这里）

### 互动设计

| 问题 | 期望答案 | 冷场备选 |
|---|---|---|
| "① 四列里几列会被标 PII？" | 群里会出现 0/1/2/3 各种答案——**这就是冲突的种子** | 讲师自曝："我第一次猜 2 列。答案是 0。我错得比你们都离谱" |
| "② 有几条藏着真人信息？" | 多数人猜 0 或 1 | 提示："想想你自己的工单——用户会在正文里写什么？" |
| "③ 9 类里几类够用？" | 群里没人敢答（因为不知道"够用"是多少） | 直接给口径："≥100 条/类，这是我们课程的默认目标值（工具里叫 `target_per_category`）" |

> ⚠️ 第 ③ 问有一个隐藏考点：**"够用"是相对口径，不是绝对真理**——它是"训练一个分类器的最小样本量"的经验值。
> 学员问"凭什么 100"时，答："凭我们要在 D5 做评估。**没有分母的指标都是废话**——这句话你今天会再听到一次。"

### 常见错误与纠偏

| 错误 | 纠偏 |
|---|---|
| 学员追问"我的那份到底过没过" | 指门禁榜："榜上只念数字，个人结论 `fde-scope gate check <你的 id>` 自己查"（不发私聊截图） |
| 学员问"能不能给我看看别人怎么写的" | "D8 的答辩会让你看到——现在给你看，你就不会自己想了" |
| 有人开始讨论"某某的委托单好水" | 立刻拉回："**我们只讲结构，不讲人。** 讲评的两份都不知道是谁写的" |
| 讲师在讲评上超时（讲到 10 分钟还没收） | **硬性**：8 分钟必须开始预注册。**预注册被挤掉 = D3 上半场白讲** |

### 承接语（最后 30 秒）

> "你们刚在群里打的三个数字，我一个都没看。
> 现在我用 25 分钟，把这三个数字一个个跑出来给你们看。
> 先说结论：**你们会有人猜对，也会有人猜错——包括我。**"

### 学员笔记要点

- G2 的三个动作：**验收主体是客户** · **第二发起人** · **放弃标准是条件句**
- 补交规则：24h 内 = **正常放行（标注"补交通过"）**；超时 = **延期通过**（作品集等级最高 B）
- 今天的三条红线：**3 个概念**（schema 探测 / PII 红线 / 覆盖度）· **结论必须三选一** · **不碰真实数据**
- 群里留下过三个猜测数字——**一会儿要对账**

## S2 · 讲与演（10–35 min · 25 min）

**本节定位**：全场唯一的"演示"段。目标不是讲清 PII 是什么，是**让学员亲眼看见"号称最干净的数据"里藏着什么**。
**本节产出的不是知识，是"证据长什么样"的样板。**

**一句话目标**（开场念）："上一节你猜了三个数。这一节我把命令行敲给你看，我们当着全场对账。"

### 分钟级时间盒

| 分钟 | 动作 | 对账哪一问 |
|---|---|---|
| 10–13 | 跑 `connect`，读 schema 表：`field / type / nullable / PII?` | 对账 ①（几列被标 PII） |
| 13–18 | **逐条看值** → 找出藏在 `content` 里的手机号与邮箱；讲 PII 红线与脱敏四步法 | 对账 ②（几条藏着真人信息） |
| 18–23 | 读 `categories` 与手工 Top/Bottom → 讲"**均匀 ≠ 够用**"；工业数据对照 | 对账 ③（几类够用） |
| 23–28 | 讲结论怎么下（三选一 + 条件句）；讲"待定"为什么是 blocker | —— |
| 28–33 | **门禁被真实拦截**：南湾汽车三条工业门禁实测 | 制造"数据问题的后果" |
| 33–35 | 收口：回到 6 节模板；埋 D4 钩子 | —— |

> ⚠️ **今天不出 `corpus` 的主角戏**：只在 13–18 分钟**借它一个数字**（`PII entities masked: 2`）做交叉验证。
> 正式锻造是 D4 的内容（[`02`](02-逐日教学大纲.md) Day 4）。**说清楚"今天只借，明天才学"**，否则学员会以为语料环节已经过了。

### 讲稿要点

**① 10–13 min｜跑 `connect`：先看"字段"，不看"结论"**

```bash
fde-scope connect --type csv --source examples/quickstart_csv/sample_tickets.csv
```

投屏读出来（终端里是一张 Rich 表格，这里抄成 Markdown）：

| field | type | nullable | PII? |
|---|---|---|---|
| `id` | string | False | （空） |
| `content` | string | False | （空） |
| `category` | string | False | （空） |
| `channel` | string | False | （空） |

底部一行摘要（**逐字念**）：

```
rows≈20 · categories=['物流查询', '退款', '账号问题', '退换货', '支付问题', '订单修改', '会员咨询', '发票咨询', '售后补发'] · channels=['chat', 'email', 'phone'] · sample_size=20
```

**对账 ① 揭晓**：

> "答案是 **0 列**。四列一个都没被标。猜 1、2、3 的举手——你看，**工具没骗你，是你在骗自己**。
> 为什么？因为 schema 表**只按字段名判**（[`12`](12-附录-术语表与模板库.md) §2.2 工具路径）。
> 列名叫 `email`、`phone`、`id_card` 才会亮 ⚠。这份数据的列名是 `id / content / category / channel`——
> **名字听起来一点问题都没有**。这就是它危险的地方。"

**顺手讲清 schema 三列的含义**（这是"schema 探测"这个概念的全部）：

| 列 | 你在读什么 | 今天要写进体检报告的 |
|---|---|---|
| `field` | 有哪些字段 | 字段清单（第 ② 节） |
| `type` | 是什么类型（string / int / float / 日期） | 类型列 |
| `nullable` | 允不允许空（`False` = 这一列的样本里没出现空） | **缺失率**（注意：`nullable=False` 只是**样本**没空，不等于全量没空） |
| `PII?` | ⚠ = **字段名**像 PII | PII 清单（第 ③ 节）——**但要先看完下面的内容** |

> ⚠️ **`nullable=False` 这个坑**：20 条样本里没空值，不代表 32,400 条里没空值。
> `sample_size=20` 是**抽样预览**，不是全量。体检报告里写缺失率时，要么问客户要全量统计，要么写"**样本内缺失率 0%，需全量复核**"——**不要写"缺失率 0%"**。

**② 13–18 min｜逐条看值：PII 藏在正文里（今天全场最贵的一分钟）**

**投屏打开 CSV 的原始行**（不要用工具，用编辑器/终端 `head`，让学员看到"真东西"）：

```bash
head -4 examples/quickstart_csv/sample_tickets.csv
```

```
id,content,category,channel
t-001,我的订单三天了还没发货麻烦帮我查一下物流谢谢,物流查询,chat
t-002,申请退款商品质量有问题已经拍照留存希望尽快处理,退款,email
t-003,无法登录账号提示密码错误但是我确定没改过,账号问题,chat
```

```bash
grep -n "13800138000\|@example.com" examples/quickstart_csv/sample_tickets.csv
```

```
4:t-004,商品破损要求换货联系邮箱 customer@example.com,退换货,email
8:t-007,已经申请退款一周了还没到账我的手机是13800138000,退款,phone
```

**对账 ② 揭晓**：

> "答案是 **2 条**。第 4 条里有一个邮箱，第 8 条里有一个手机号——**都在正文里，不在任何一列的名字里**。
> 同志们，这就是今天最贵的一句话：

投屏，全天常驻：

```
不亮 ≠ 没有 PII。自由文本必须逐条看值。
```

fde-scope corpus --input examples/quickstart_csv/sample_tickets.csv --out /tmp/fde-d3-demo/corpus_report.html
```

输出里有一行（**只看这一行，其他明天讲**）：

✅ PII entities masked: 2
```

> "工具在**清洗阶段**把这两条揪出来了。注意这个先后顺序——
> `connect` 说'没有 PII'，`corpus` 说'我遮了 2 个'。
> **两个结论都对，因为它们看的不是一个东西**：一个看列名，一个看内容。
> 这就是为什么体检报告第 ③ 节不能只抄 `connect` 的输出。"

**然后讲红线——今天必须逐条念，不许带过**（[`11`](11-工具与环境准备.md) §6.1）：

| # | 红线 | 现场话术 |
|---|---|---|
| 1 | 只用两类数据：课程自带虚构数据，或**你自己已脱敏并经公司同意**的数据 | "这份 CSV 是虚构的，脚本里写死了免责声明。**你公司的数据不是**" |
| 2 | 真实客户名与 PII 不进群、不上传（含作业、截图、提问里的粘贴内容） | "有人上周把工单截图发群里问我——**那张截图就是一次数据合规事故**" |
| 3 | 不进任何第三方工具：在线标注平台、在线 JSON 格式化、网盘、聊天机器人 | "包括你现在正在用的那个 AI 助手。**包括我**" |

**PII 的判断标准只有一句话**（[`11`](11-工具与环境准备.md) §6.2）：

> "**这条信息能不能定位到具体某个人？** 能 → 按 PII 处理。"

**处置方法讲"脱敏四步法"**（[`11`](11-工具与环境准备.md) §6.4）——只讲前两步，后两步留给自练路径 B：

| 步 | 动作 | 例 |
|---|---|---|
| 1 拿掉 | 与任务无关的 PII **直接删列** | 客户表里的身份证列 |
| 2 替换 | 保持格式、换掉内容 | `13800138000` → `13800000000` |
| 3 哈希 | 需要保留关联性时 | 用户 ID → `u_3f9a…`（同人同哈希） |
| 4 保真 | 分布、长度、语言风格不变 | 脱敏后仍能被质量门正常处理 |

> ⚠️ 讲师提醒：**脱敏不是"遮住了就行"**。第 4 步"保真"才是专业分水岭——
> 把手机号全部替换成 `1` 之后，这类样本在语料里就废了（长度分布、格式特征全没了）。
> 一句话："**你脱敏后的数据，还要能被当成数据用。**"

**④ 23–28 min｜结论怎么下：三选一，且必须带条件**

投屏 [`12`](12-附录-术语表与模板库.md) §2.2 第 0 节的示例结论，逐字念：

> "**有条件能做**：现有 32,400 条工单可支撑意图分类，但退款类样本仅 12 条，
> 需在 D4 补盲 ≥200 条，否则该场景**不纳入验收范围**。"

然后拆解这句话的三个动作：

| 动作 | 这句里的对应 | 为什么必须有 |
|---|---|---|
| 先给**总体判断** | "有条件能做" | G3 ③ 是 blocker，三选一，**没有第四项** |
| 给**条件**（可核对的事实） | "退款类样本仅 12 条" | 这是从覆盖度表里抄来的**真实数字**，不是你感觉的 |
| 给**后果**（触发条件句） | "否则该场景不纳入验收范围" | 这就是 D2 的**放弃标准**在数据层的回声 |

**然后讲"待定"为什么不可接受**：

> "有人会说：'我还看不出来，先写待定，D4 再定'。
> 不行。因为**客户不是等你写完报告才做决定**——他今天下午就要回答老板'这个项目能不能上'。
> 你写待定，他就只能说'不知道'。**你交付的是判断，不是材料。**
> 犹豫怎么办？**犹豫就写条件**：'若能补齐 X 字段则能做，否则不能做'——这是判断，不是待定。"

**本节定位**：全场把 S2 的方法**用在自己的数据上**，并在"接数据"这个动作上**被助教当面设坑**。
**本节的成功判据不是"报告写完了"，是"PII 那一栏写了自己的判断"。**

**一句话目标**（开场念）："35 分钟，你只做一件事——把 S2 那三个数字，换成你自己数据上的三个数字，然后写下一句自己的结论。"

### 分组建档复核（讲师，1 分钟）

D2 已分好组，本节**只复核，不重分**（[`07`](07-实战剧本与案例库.md) §2.2 / §2.3）：

| 组 | 案例（D2 定稿的委托单） | 今天练的数据 |
|---|---|---|
| **A 组** | 案例 B · 迅捷出行（网约车 · ticket） | `examples/quickstart_csv/sample_tickets.csv`（20 条虚构工单，代表"抽样体验"） |
| **B 组** | 案例 C · 南湾汽车（整车厂 · manufacturing） | `examples/quickstart_manufacturing/alarm_corpus.jsonl`（12 条虚构报警）+ 同上的 CSV |

> ⚠️ 讲师提醒：**A/B 两组今天都用同一份 CSV 起步**（[`02`](02-逐日教学大纲.md) Day 3 时间盒）。这不是偷懒——
> 目的是让两组在**同一份数据**上做出**不同的结论**：A 组看的是"客服工单能不能训分类器"，
> B 组看的是"这套数据方法能不能迁移到工业场景"。B 组额外跑 `alarm_corpus.jsonl` 找**迁移感**。
> D8 交叉提问时，两组要互相解释对方的数据形态。

### 分钟级时间盒（学员视角）

| 分钟 | 做什么 | 为什么这么排 |
|---|---|---|
| 0–5 | **先猜后看（第二轮）**：写下三个数字——① 我猜 PII 有几条 ② 我猜最长尾的类是哪个 ③ 我猜几类够用（≥100 条） | 必须先落笔，再看屏；写下来才有冲突 |
| 5–12 | 跑 `connect`，抄 schema 表；**逐条看值**找 PII | 工具最快的部分，先拿确定性 |
| 12–20 | 填第 ②③ 节（字段清单 + PII 清单与处置）——**处置建议必须自己写** | 报告里唯一"工具给不出"的部分，精力最好时做 |
| 20–27 | 跑 `corpus`，数 Top/Bottom，填第 ④ 节（覆盖度）+ 第 ⑤ 节（≥3 条质量风险） | 需要动脑归纳，放在中段 |
| 27–32 | 写第 ⓪ 节（一句话结论，三选一）+ 第 ① 节（概况）+ 第 ⑥ 节（下一步建议） | 结论要基于前面所有证据，放在最后 |
| 32–35 | 自查 G3 四条 + 准备 S4 交换 | 留够时间，别卡在最后一分钟 |

> ⚠️ **助教巡场时序**（三趟，每趟约 10 分钟，覆盖全部桌）：
> 第一趟（5–15 min）以**客户 IT 主管**身份送数据（三个坑）；第二趟（15–25 min）看 PII 处置建议；第三趟（25–35 min）**只问一句**"你的结论是哪三个字？"

### 讲稿要点

**① 先猜后看（第二轮）——为什么还要猜一次**

> "S2 我已经当着你们跑过一遍了，为什么还要猜？
> 因为 S2 我**只揭晓了 PII 那一条**（2 条）。另外两条——**最长尾的类是哪个、几类够用**——
> 我一个字都没说。而且，你们马上要看的**不是同一份数据**（B 组还有报警日志）。
> 更重要的是：**在真实项目里，你永远没机会'先看一遍'。**
> 你拿到数据之前，就要能说出你怕什么。"

**猜的三个数写在哪里**：写进体检报告的最上面，标注 `【预注册】` ——**这三个数要留着**，
S4 互检时对方要看，D5 做评估时还要对账（"你当时猜 70% 能用，实测 3%"）。

**② 助教巡场剧本（[`07`](07-实战剧本与案例库.md) §3.2）——三个坑，逐桌埋**

助教扮演**客户 IT 主管**，把数据"送"给学员（口头 + 指屏幕）。**三个坑必须按顺序埋**：

| # | 助教台词（原话） | 坑在哪 | 学员应该做什么 | 助教怎么判 |
|---|---|---|---|---|
| 1 | "这是我们能给的**全部**字段了。" | 数据里含 PII（正文里的手机号 / 邮箱 / 工单号） | **挑出来说"这个不能收"**——点明处置方式（删列 / 替换 / 不入场） | 敢不敢说"不收"（[`11`](11-工具与环境准备.md) §6.1 红线 2） |
| 2 | "类别分布很均匀的，放心。" | 分布**确实**均匀（熵 0.9569），但**每一类都远不够**（1–3 条 vs 需 100） | **当场用工具输出反驳**：把 `gaps: 9` 与每类绝对量摆出来 | 是否先看再装（有没有真去数） |
| 3 | "时间范围？**大概是**去年的吧。" | "大概"= 一个不能进报告的字段 | 把"大概"变成**确认项**：写进第 ① 节"待客户确认"，或明确标注"未确认" | 有没有把模糊信息**变成待办**，而不是照抄 |

**助教扮演纪律（讲师提前给助教看这三条）**：

1. **不许一次放行**——学员说"好的我收下"时，追问"你确定？要不要再翻翻？"（给第二次机会，但**只给一次**）
2. 学员反问时**照实回答**（问"有没有手机号"→"你们自己看"），**不许顺着学员说**
3. 学员点破坑时，**当场承认**并追问一句"那你写进报告的哪一节？"——把口头判断逼成**书面判断**

**③ 车间主任（B 组可选，[`07`](07-实战剧本与案例库.md) §4.4）**

B 组有一个额外彩蛋：讲师（或助教）以**焊装车间主任**身份路过，说一句：

> "你们坐在办公室吹空调，知道焊装线停线赔多少吗？"

**触发条件**：如果学员说"要停线做数据采集"或"要接 PLC 控制层"→ 主任**立刻炸**（表演）。
**通过标准**：学员主动把"**旁路采集、不碰 PLC 控制层、只读数据**"写进报告的第 ⑥ 节（下一步建议）。
**通过暗号**：学员问"FAT 阶段你们能安排哪个窗口？"→ 主任给一个 **2 周后的停机维护窗口**（这一问是 D5 的预演）。

> ⚠️ 讲师提醒：这个彩蛋**只有 B 组有**，A 组不要演——A 组的场景里没有车间。
> 如果时间紧，**砍掉彩蛋，不许砍三个坑**（三个坑是 G3 的直接考点）。

### 投屏·板书

- 左：**35 分钟时间盒**（学员视角那张表，常驻，让他们自己控节奏）
- 中：**体检报告 6 节骨架**（[`12`](12-附录-术语表与模板库.md) §2.2）
- 右：**三个坑的问题清单**——只显示"该问的问题"，不显示答案：
  ```
  ☐ 这份数据里，哪些字段/内容能定位到具体某个人？
  ☐ 类别分布的 Top / Bottom 分别是多少条？
  ☐ 你说的"能用"，分母是多少？
  ☐ 时间范围、总量、采集方式——哪些是确认过的？哪些是"大概"？
  ```
- 白板角落：停车位

### 互动设计

| 环节 | 讲师动作 | 目的 |
|---|---|---|
| 0–5 min | 全场安静写三个数（**不许说话**） | 把"预注册"变成一次仪式——落笔才算数 |
| 巡场第一趟 | 助教按剧本埋坑 | 制造"接数据"的真实压力 |
| 巡场第二趟 | 随机抽 2 桌，当众念他们的 PII 处置建议（**匿名，念动作不念名字**） | 让"敢说不收"被公开表扬一次 |
| 收尾 1 min | 全班举手："结论写了'有条件能做'的举手？'能做'？'不能做'？" | 三个选项**都有人举**才是健康的——说明有真判断 |

> 💡 讲师提示：如果**全班都写"能做"**，立刻停下来问一句：
> "谁的数据里连一个'待客户确认'都没有？**没有待确认项，说明你没细看。**"

### 学员动作（现场）

- 写下三个预注册数字（**先于**跑命令）
- 跑 `connect` + 逐条看值，产出第 ②③ 节（字段清单 + PII 清单与处置）
- 跑 `corpus`，产出第 ④⑤ 节（覆盖度 + ≥3 条质量风险）
- 写第 ⓪①⑥ 节（结论 / 概况 / 下一步建议）
- 被助教"送数据"时**敢说"这个不能收"**，并把判断**写进报告**
- 自查 G3 四条

### 常见错误与纠偏

| 错误 | 纠偏（讲师/助教用） |
|---|---|
| 学员把 `connect` 的输出整段贴进报告，不做判断 | 追问"**处置建议**那一列呢？"——工具没有这一列，这是你的活 |
| 学员写"PII：无" | 让他**逐条看一遍值**（`grep` 手机号 / 邮箱 / 身份证正则），再回来改 |
| 学员的结论是"待定" | 不批评，只问"你缺哪个信息才能下结论？写出你的条件"→ 改写成条件句 |
| 学员把"大概去年"照抄进第 ① 节 | 要求改写为"**时间范围：待客户确认（口头为'大概去年'）**"——把模糊变成待办 |
| 学员纠结"要不要问客户要全量数据" | 记进第 ⑥ 节"下一步建议"——**今天不用拿到，但今天必须写下要什么** |
| 学员拿自己公司的真实数据来跑（路径 B） | **立即私聊**，要求撤回重交；引用 [`11`](11-工具与环境准备.md) §6.1（**违规 = 数据合规事故**，[`03`](03-评估体系与通关门禁.md) §8 一票否决项） |
| 学员只写了 1 条质量风险就停手 | "G3 ④ 要 ≥3 条"，给三个方向：**缺失 / 重复 / 口径不统一 / 长尾不足 / 已知局限** |

### 承接语（最后 30 秒）

> "停笔。现在做一件事：**把你手里的报告，和旁边那位换。**
> 你只有 10 分钟，任务只有一个——**找出他漏掉的那个风险。**"

### 学员笔记要点

- **预注册三个数**必须落在纸上，S4 与 D5 都要对账
- **三个坑的原话**：全部字段 / 分布很均匀 / 大概是去年的 → 对应动作：**不收** / **反驳** / **变成待办**
- 报告里**唯一工具给不出**的两列：**处置建议**（第 ③ 节）与**质量风险**（第 ⑤ 节）
- 结论三选一，**犹豫就写条件句**

## S4 · 复盘（70–80 min · 10 min）

**本节定位**：10 分钟做两件事——**相邻互检**（找对方漏掉的 1 个风险）与**命名反模式**。
**这一节的价值不在"改好了"，在"看见自己的盲区"。**

**一句话目标**（开场念）："你做体检的时候，一定会漏东西。今天让同桌替你找出来——比让客户找出来便宜一万倍。"

### 分钟级时间盒

| 分钟 | 动作 | 目的 |
|---|---|---|
| 70–74 | **相邻两人交换**，各找出对方漏掉的 **1 个风险**（必须具体到条款/字段） | 用第二双眼睛补盲 |
| 74–77 | 抽 **2 组**当众念"我发现了什么"（**念发现，不念人名**） | 把个案变成公共知识 |
| 77–79 | **命名反模式**：Data Quality Surprises + 三条高频漏项 | 给错误一个名字，才记得住 |
| 79–80 | 收口 + 接 S5 | —— |

### 讲稿要点

**① 互检怎么说（70–74 min）——给三句提问模板**

轮到互检时，学员常常尬聊。直接投屏三句话，让他们照着问：

```
1. "你这份数据里，哪一列/哪些内容能定位到具体某个人？——我在你的报告里没看到 X。"
2. "你说'能用'，分母是多少？（每类多少条？目标多少条？）"
3. "第 ① 节里，哪几个字段是你**确认过**的？哪几个是'大概'？"
```

> "三句话对应三件事：**PII 漏没漏、覆盖度有没有量、事实与推测有没有分开。**
> 找不出问题的，说明你俩漏在了同一个地方——**那更值钱**，正好一起补。"

**② 抽 2 组当众念（74–77 min）——只念"发现"**

标准句式（让学员照念）：

> "我在 <第 X 节> 发现 <具体缺失>，我的建议是 <动作>。"

例（讲师可以示范一遍，用自己"漏掉"的例子最好）：

> "我在第 ③ 节发现他只写了'涉及手机号'，没写**处置方式**——PII 清单是 blocker，
> 但 blocker 要的是'清单 **与处置建议**'。我的建议是补一句'正则替换为 `<PHONE>`，脱敏后入语料'。"

> ⚠️ 讲师注意：**不许点评人，只点评发现**。哪怕发现得很轻，也先肯定"这条确实是漏项"。
> 10 分钟里被打击一次的人，S6 会直接不交。

**③ 命名反模式（77–79 min）——给今天最好的名字**

投屏 [`12`](12-附录-术语表与模板库.md) §1.6 第 9 条，逐字念：

```
| 9 | Data Quality Surprises 数据质量惊吓 | 假设"数据已经治理好了" | 开工先做数据体检（G3） |
```

> "这个反模式叫 **Data Quality Surprises**——**数据质量惊吓**。
> 它的定义只有一句话：**假设'数据已经治理好了'。**
> 今天你们看到的三件事，全是它的后果：
> ① 四列没标 PII，你以为干净——**结果正文里躺着手机号和邮箱**；
> ② 客户说'分布很均匀'，你以为够用——**结果 9 类全部不达标**；
> ③ 客户说'大概是去年的'，你以为有范围——**结果你连时间范围都没确认。**
>
> 反制动作只有一个：**开工先做数据体检。** 就是你们刚才做的那件事。"

**四条高频漏项清单**（讲师按当天实际提交挑，通常落在这四条）：

| # | 高频漏项 | 一句话矫正 |
|---|---|---|
| 1 | PII 只写"有"，没写**处置方式** | G3 ② 要的是"清单**与处置建议**"——没写怎么处理 = 没写 |
| 2 | 覆盖度只写"不均匀"，没写**绝对量** | 每个类别都要有数字（Top / Bottom 都要） |
| 3 | 结论写成"待定 / 建议进一步分析" | 三选一；**犹豫就写条件句** |
| 4 | 事实与推测混在一起 | "确认过的"与"大概是"必须分栏写——第 ① 节加一列"确认状态" |

**④ 收口（79–80 min）**

> "你们的报告现在至少被两双眼睛看过——**你自己的，和同桌的**。
> 待会儿自练时段，你要把它改到能交给客户的程度。
> 因为明天，你要拿它**换**一沓语料。"

### 投屏·板书

- 左：**三句互检提问模板**（常驻 10 分钟）
- 中：**Data Quality Surprises → 开工先做数据体检（G3）**
- 右：**四条高频漏项**（讲师按当天实际挑，写满四条）
- 白板角落：停车位

### 互动设计

| 环节 | 讲师动作 | 目的 |
|---|---|---|
| 交换 | 计时 4 分钟，**时间到必须停** | 防止互检变成聊天 |
| 当众念 | 只抽 2 组（10 分钟里超过 2 组就变成拖堂） | 保持节奏 |
| 命名 | 念完反模式后问一句"谁今天被'惊吓'到了？举个手" | 用笑声收尾，同时把概念钉住 |

### 学员动作（现场）

- 交换报告，找出对方**漏掉的 1 个风险**（具体到节 / 字段）
- 记录对方给自己找出的漏项（**待会儿 S6 要改**）
- 抄下反模式名与四条高频漏项

### 常见错误与纠偏

| 错误 | 纠偏 |
|---|---|
| 互检变成"你写得真好"式互夸 | 拉回："**今天不是互夸，是互相找漏。找不出来才尴尬**" |
| 学员发现漏项后开始重写对方报告 | 拦住："**只记不改**——他的报告他改，你的时间用来找下一个漏项" |
| 有人借机指出"某人数据来源不合规" | 立刻私下处理（走 [`11`](11-工具与环境准备.md) §6.7 违规处置流程），**不当众指控** |
| 超时（10 分钟讲成 15 分钟） | **硬性**：11 分钟必须切 S5。没念完的组，S6 群里补 |

### 承接语（最后 30 秒）

> "报告你已经有底稿了。接下来的 10 分钟，我告诉你**明天你要拿什么来换它**。"

### 学员笔记要点

- **反模式 Data Quality Surprises**：假设数据已治理好 → 反制 = 开工先做数据体检（G3）
- **四条高频漏项**：PII 没处置 / 覆盖度没绝对量 / 结论待定 / 事实与推测混写
- 互检三句：**哪列能定位到人？分母是多少？哪些是"大概"？**

## S5 · 布置 G3 + 明日预告（80–90 min · 10 min）

**本节定位**：把今天的产出物变成一条**可提交的规则**（G3 四条 + 命名 + 截止 + 补交），并埋死 D4 的钩子。
**这一节不许讲新知识。**

**一句话目标**（开场念）："接下来 10 分钟全是规则——听清楚，今天不用问第二遍。"

### 分钟级时间盒

| 分钟 | 动作 | 目的 |
|---|---|---|
| 80–84 | 念全 **G3 四条**（blocker / warning 分开念） | 让"过没过"可自查 |
| 84–86 | **命名规范 + 截止 + 补交规则** | 减少后台扯皮 |
| 86–89 | **明日预告**：D4 的三个钩子 | 建立连续性 |
| 89–90 | 移交 S6 + 助教值守规则 | —— |

### 讲稿要点

**① G3 四条怎么念（80–84 min）——blocker 与 warning 分开念**

投屏（[`03`](03-评估体系与通关门禁.md) §3 G3 行原文）：

```
① 字段清单含类型与缺失率
② PII 清单与处置建议
③ 明确结论"能做 / 不能做 / 有条件能做"
④ ≥3 条质量风险

①②③ = 🚫 blocker（硬拦）
④   = ⚠️ warning（能过，但进作品集评分）
```

> "念法解释一下：**①②③ 缺一条，你的门就是红的**——不是'部分完成'，是不通过。
> ④ 是 warning：**它不拦你，但会在 D8 评分表上扣你的分**（[`03`](03-评估体系与通关门禁.md) §4）。
> 所以别问'④ 能不能少写一条'——**能不能过是一回事，拿几分是另一回事。**"

**今天就顺手自查一次**（现场 30 秒，别拖）：

```bash
COLUMNS=200 fde-scope gate check <你的档案id>
#   id 从哪来：COLUMNS=200 fde-scope engage list
#   ⚠ 在 qualification 阶段，不带 --gate 时会打印
#     "Phase 'qualification' has no gate." —— 这是正常输出，不是报错
```

> ⚠️ **讲师必讲的一段**（[`12`](12-附录-术语表与模板库.md) §3.2 / §3.5）：
> **"ticket 档案上不要手动去查工业门禁。** 比如 `--gate site_survey`，它会回你一个 `✅ PASS`——
> 那是'没有可检查的数据'的**空过**，不是通过。**别把这个 ✅ 当成证据写进作品集**，
> 一眼就能被人看穿。**判断'我该过哪几关'，只认 [`03`](03-评估体系与通关门禁.md) §3 的 G0–G8 课程门禁。**"

**② 命名 + 截止 + 补交（84–86 min）**

| 项 | 规则 |
|---|---|
| 命名 | `D3-姓名-数据体检报告`（例：`D3-张三-数据体检报告.md`） |
| 提交 | 群里提交（**只交报告本身**，不交数据文件、不交截图、不交 CSV） |
| 截止 | **直播次日 21:30**（运营催交时间） |
| 补交 | 24 小时内补交 = **正常放行（标注"补交通过"）**；超 24 小时 = **延期通过**，作品集等级最高 B（[`03`](03-评估体系与通关门禁.md) §3） |
| 红线 | **报告里不得出现真实客户名与 PII**（含截图）——[`11`](11-工具与环境准备.md) §6.5：截图前 3 秒检查姓名 / logo / 域名 / 工单编号 |

**③ 明日预告（86–89 min）——三个钩子，逐条说**

> "明天 D4，'把矿石炼成金属'。三件事先说在前面：
>
> **第一，我会当场问你一句：'你补的那些样本，有多少是你编的？'**
> ——不是刁难。客户一定会问这句。你答不上来，你今天就白补了。
>
> **第二，明天我要你写一段不超过 200 字的**人话**，和一个'老板'讲清楚你干了什么。**
> 那段话里**不许出现**这些词：语料、覆盖度、合成数据、去重、准确率、模型、推理、向量、embedding、token。
> 一个都不许。[`12`](12-附录-术语表与模板库.md) §2.3 里有完整禁用词表——今晚可以先看一眼。
>
> **第三，明天的坏消息是：指标一定不好看。**
> 我今天先把这话说死——**指标难看是正常的，难看正是它存在的价值。**"

**④ 移交 S6（89–90 min）**

> "接下来的 45 分钟归你们。助教在群里值守——**只回答两类问题**：规则类，和'这条风险算不算一条'。
> 案例背景的标准答案和方案类问题，明天再问。"

## S6 · 自练（+45 min）

**本节定位**：不讲课，学员自己做完并提交。助教在群里值守答疑。
**这一节的成功判据只有一个：提交率。** 讲师课后统计，未交者次日 08:30 前私聊。

### 45 分钟怎么分（投屏建议）

| 分钟 | 做什么 | 为什么这么排 |
|---|---|---|
| 0–10 | 按 S4 互检的漏项**改报告**（PII 处置 + 事实/推测分栏） | 记忆最新，改起来最快 |
| 10–20 | 补齐第 ⑤ 节质量风险到 **≥3 条**（写足 4 条更稳） | 归纳类工作，需要连续思考 |
| 20–30 | 写第 ⓪ 节结论（三选一 + 条件句）+ 第 ⑥ 节下一步建议 | 结论必须基于已改完的证据 |
| 30–38 | 通读 + 删掉所有"大概 / 可能 / 有待观察" | 删模糊词 = 最后一次自检 |
| 38–45 | 自评 G3 四条 + 提交 | 留够提交时间，别卡在最后一分钟 |

### 三条路径（学员按自己情况选一条）

| 路径 | 适合谁 | 做什么 |
|---|---|---|
| **A · 完成**（推荐） | 所有人 | 用 `examples/quickstart_csv/sample_tickets.csv`（A 组）/ 加 `alarm_corpus.jsonl`（B 组）完成体检报告 → 自评 → 提交 |
| **B · 迁移** | 手头有真实数据的人 | 用**你自己已脱敏并经公司同意**的数据重做一份（[`11`](11-工具与环境准备.md) §6.4 脱敏四步法：拿掉 / 替换 / 哈希 / 保真）。**红线：真实客户名与 PII 不得出现在提交物里，也不得投屏** |
| **C · 加练** | 想多练手的人 | 跑 `fde-scope connect --type csv --source examples/quickstart_manufacturing/station_samples.jsonl --dry-run`，体会"**不读数据先看计划**"；再对 `alarm_corpus.jsonl` 写一份**只含第 ③④ 节**的迷你体检（12 类故障的覆盖度缺口 + 工业场景的 PII 判断） |

> 关于路径 C：**只写两节（PII 与覆盖度）。** 目标是把"同一套方法换一个场景"这件事练成肌肉记忆——
> 工业数据里 `PII entities masked: 0` 不代表没有红线，只代表红线不在报警日志里。

### 完成标准（提交前逐条打钩）

```
☐ 第 ⓪ 节结论是三个词之一（能做 / 不能做 / 有条件能做），且带条件句
☐ 第 ② 节每个字段都有【类型】和【缺失率】（样本内缺失率须标注"样本内"）
☐ 第 ③ 节每个 PII 都有【处置建议】（不是只写"涉及手机号"）
☐ 第 ④ 节给出 Top / Bottom 的绝对条数，并指出长尾盲区
☐ 第 ⑤ 节质量风险 ≥3 条，每条都能对应到一个具体字段或类别
☐ 全文没有"待定 / 建议进一步分析 / 可能 / 大概"（除非明确写成"待客户确认"）
☐ 三个预注册数字还在报告里（标注【预注册】）
☐ 命名 D3-姓名-数据体检报告
```

### 卡点急救

| 卡在哪 | 怎么救 |
|---|---|
| "我不知道缺失率怎么算" | 用 `connect` 的 `nullable` 列 + 样本实际空值数：`样本内缺失 = 空值数 / 样本行数`，**表头写清"样本内（n=20）"**——不要写成全量缺失率 |
| "PII 处置建议写什么" | 套四步法：**拿掉**（与任务无关的列）/ **替换**（保持格式换内容）/ **哈希**（要保留关联时）/ **保真**（脱敏后仍可用）。逐条挑一个写 |
| "我只有 2 条质量风险，凑不出 3 条" | 从这五个方向找：**缺失**（空值/字段缺）、**重复**（跨月重复工单）、**口径不统一**（标签定义不一致）、**长尾不足**（覆盖度缺口）、**已知局限**（方言/口语化） |
| "结论我写不出来" | 三步走：① 哪一类**现在就能用**？② 哪一类**缺多少**？③ 缺的这类**要不要纳入验收范围**？把 ③ 的答案写成条件句 |
| "我的数据没有 PII，第 ③ 节写什么" | 写"**未检出**"并**写清依据**："按字段名与样本值双向检查，样本内未检出具定位性的 PII；全量需客户确认"——**别写"无 PII"** |
| "时间范围客户没给" | 写成 **"待客户确认"** 是一个合格答案——**但必须出现在第 ⑥ 节"下一步建议"里**，别只写在第 ① 节 |

### 助教值守规则

- **只回答两类问题**：① 规则类（命名 / 截止 / 格式 / 工具报错）② "这条算不算一条质量风险"
- **不回答**：案例背景的"标准答案"（会破坏 D8 交叉提问）、D4 之后的实现与方案类问题
- 每 15 分钟在群里发一次进度提示（"还有 30 / 15 / 5 分钟"）
- 收到提交后**只回一个字**：`✓`（不讲评——讲评在次日 08:30 门禁榜 + D4 回炉）
- 遇到真实客户名 / PII 出现在提交里 → **立即私聊要求撤回重交**，并记录合规日志（[`11`](11-工具与环境准备.md) §6.7）

### 学员动作

- 45 分钟独立完成（路径 A / B / C 三选一）
- 自评 G3 四条
- 提交 → 收到 `✓`
- 在群里写 60 秒收获：「**我今天猜错的那一个数字是什么？我原来以为 ___，实测 ___。**」

### 常见错误与纠偏

| 错误 | 纠偏（助教用） |
|---|---|
| 学员把体检报告写成"工具输出汇编" | "**工具能给的你都给了，工具给不了的你一个字没写。** 处置建议、质量风险、结论——这三样才是你的报告" |
| 学员的结论是"数据质量一般，建议进一步分析" | 打回：**"待定"= 未达**（红线 2）。追问"你缺什么才能下结论？"→ 改成条件句 |
| 学员提交里出现真实公司名 / 手机号 / 邮箱 | **立即私聊 + 撤回**，引用 [`11`](11-工具与环境准备.md) §6.1 / §6.7（违规 = **数据合规事故**） |
| 学员把 seed 档案（如迅捷出行）的参考数字原样抄来 | 不禁止，但**次日回炉会点名问**："你这份数据的 `diversity_index` 是多少？"——抄的人答不上来 |
| 学员只交了字段表，没交结论 | 打回：**③ 是 blocker，缺一条就是没过**（[`03`](03-评估体系与通关门禁.md) §3） |
| 学员问"复现一次数字不一样怎么办" | 先用**同一条命令同一样本**复现；不一致就写进报告"**复现差异**"——这是 G5（可复现）的提前预演 |
