## 1. GTM 页（可直接粘贴）

### 1.1 一句话

> **这门课不解释 FDE，只炼金**——8 天，把 4 区 18 阶段的交付链路亲手走一遍，带走 8 件拿得出手的产出。

### 1.2 电梯稿（30 秒版）

```
市面上的 FDE 内容大多停在"概念解释"：FDE 是 Palantir 发明的、薪资很高、要懂技术又懂业务。
这些话没错，但解释不等于会用。

这门课用 8 天，让你亲手跑通一条完整的交付链路：
定边界 → 接数据 → 造语料 → 验证评估 → 运维化 → 交接沉淀 → 变现。

每天一道门禁，每天交一件老板和客户看得懂的产出。
第 8 天你手里不是笔记，是一套作品集，和一套话术。

不需要会写 Python，不需要 API key，也不需要换掉你现在用的工具。
```

### 1.3 三条卖点（每条都能当场验证）

1. **门禁是工程，不是清单。** 通关不是"看完了、考过了"，而是产出物过机器校验 + 讲师按量表打分。
   线上可当场演示：推进阶段时门禁**实时复评**，条件不满足就 `blocked`——不是靠自觉。
2. **零门槛、零 key。** 全链路核心证据不需要 API key、不需要 Docker、不需要 GPU，本机可跑；
   LLM 只是**可选加速**（关掉它整条链路照样走通）。对照：多数认证课要求 Python / 云基础先修。
3. **交出去的是作品集，不是结业证。** 8 件产出里有 Runbook、SLO 卡、值班交接卡、交接包——
   是接手的人真正要读的东西，不是"我学过"的证明。

> 三条都能被验证，而"验证方式"本身写进了课程： [`03`](03-评估体系与通关门禁.md) §4 评分量表、[`11`](11-工具与环境准备.md) §4.1 无 key 路径。

### 1.4 时间承诺（只说能核对的口径）

以 [`02`](02-逐日教学大纲.md) 的逐日时长为准（可逐条核对）：

| 天 | 投入 | 形态 |
|---|---|---|
| **D1 入门日** | **6 小时**（上午 3h + 下午 3h） | 线上直播 |
| **D2–D8**（每天） | **直播 90 分钟 + 自练 45 分钟** = 2.25 小时 | 直播 + 任务卡 |
| **整期合计** | **约 22 小时** | 8 天 |

排期与形态（连续 8 天 / 隔天 2 周 / 4 周自学 / 企业 3 天压缩）→ [`04`](04-交付实施手册.md) §2。

> ✅ **口径已统一**：早期 [`README`](README.md) 开头的"16–20 小时"是按均值粗估的口径，
> 现已改为与 `02` 一致的**约 22 小时**（D1 = 6 小时 + D2–D8 每天 2.25 小时）。
> 对外一律用本表的逐日口径——它能被逐条核对，而"16–20 小时"不能。

### 1.5 价格与档位（按 [`04`](04-交付实施手册.md) §1.2）

四档，其中**一档真免费**——这是 2026-09 起对外可以说的话：

| 档位 | 形态 | 包含什么 | 对外怎么报价 |
|---|---|---|---|
| **L0 免费公开版** | B 的公开子集 | 网页版全部课文 + 工具链 + 自学路径 | **¥0，永久免费**；不设名额、不用报名。**可以写进招生页** |
| **L1 标准档** | A. 线上直播训练营（默认） | 8 天直播 + 助教 1:15–20 + 每日门禁 + 答辩评级 + 证书 + 结营包 | 按 `04` §1.1 的公式逐期算；对外说"**档位 + 预约沟通**" |
| **L2 影子项目档** | D. 影子项目（加档） | L1 全部 + 真实小场景准入 + 导师 ≤1:3 + 脱敏双签产出 | 一例一议；对外说"**需先完成 L1 且通过准入四件套**" |
| **L3 企业内训档** | C. 企业内训 | 3 天集中 + 1 周作业 + 客户脱敏场景 + 内训考核对接 + 对公发票 | 项目制报价；对外说"**按人天费率 × 人数 + 定制案例人时**" |

对外话术的三条边界：

1. **L0 的数字可以直接说**（¥0），因为它不依赖任何未定变量。
2. **L1–L3 只说结构，不说数字**——成本公式逐期不同，写死会变成承诺（算法见 [`04`](04-交付实施手册.md) §1.1）。
3. **不说"起价"**。"¥X 起"仍然是数字，仍然会被当成承诺，仍然要逐期兑现。

> **这一条已经从劣势变成部分补齐**：竞品多数明码标价（见 §4.4），我们现在能公开 L0 的价格、
> 四档的包含项与**不包含项**、以及每期招生页必须给出的三件事（[`04`](04-交付实施手册.md) §1.2）。
> **仍未补齐的部分**：L1–L3 没有公开数字。已记入 §6 第 6 项。

## 2. 适合谁 / 不适合谁

| 适合 | 不适合 |
|---|---|
| 刚入职 / 即将入职的 FDE、交付工程师（企业内训尤佳） | 想学模型训练、微调、算法竞赛的人 |
| 想转型的技术人：测试、运维、前端、数据、后端 | 完全不碰电脑、不愿敲命令行的人 |
| 想进 AI 交付赛道的应届生、产品经理、售前、实施 | 只想听概念、不做作业的人 |
| 已在客户现场、但总在"救火"没有章法的工程师 | 期待"包就业 / 包涨薪"的人 |

**先修要求（很低）**：能装软件、能复制粘贴命令行、能读懂表格。不需要会写 Python。

## 3. 学完拿走什么

**8 件产出（作品集）**：迷你链路证据 + 世界观 → 客户委托单 → 数据体检报告 → 语料报告 + 话术
→ Demo + bad case → Runbook + SLO + 值班交接卡 → 交接包 + 技能卡 → 作品集三套包装。

**9 道门禁（G0–G8）**：每道门禁 = 产出物 + 证据 + 讲师按 [`03`](03-评估体系与通关门禁.md) §4 量表打分；
**"诚实标注"得 0 分一票否决**，**用真实客户数据练习也一票否决**（作品失效 + 证书取消）。

**结业等级**：A / B / C 三档，按产出完整度与平均分评定，标准见 [`03`](03-评估体系与通关门禁.md) §6。

## 4. 横向对比

### 4.1 用这五个维度比

选维度比"比谁家内容多"有用。买 FDE 课的人真正要判断的是这五件事：

1. **投入**——能不能排进我的日程（几小时 vs 几个月）
2. **动手程度**——听讲 / 看视频 / 交作业 / **亲手跑通一条链路**
3. **产出物**——学完手里有什么（笔记？证书？能演示的东西？）
4. **评估方式**——怎么证明学会了（看完？考试？**产出过校验**？）
5. **背书**——发不发第三方证书、雇主认不认

外加一个价格维度，因为它是唯一的硬数字。

## 5. 优势（诚实版，每条落在一个可核对的事实上）

1. **门禁是工程，不是清单。** 通关靠产出物过校验，不靠自觉或选择题。可现场演示
   `engage advance` 被 `blocked`。[`03`](03-评估体系与通关门禁.md) §1.1
2. **产出覆盖完整交付链，不是单点技能。** 8 件里有 Runbook、SLO 卡、值班交接卡、交接包、合规六件套——
   多数竞品止步于"做出一个 RAG / Agent demo"。
3. **零门槛、零 key、不换工具。** 不需要 Python，不需要 API key，不要求替换你现有的编码 / 办公 Agent；
   课程只叠"流程与门禁层"。[`01`](01-课程设计说明书.md) §6.4、[`11`](11-工具与环境准备.md) §4.1
4. **平台层开源可审计。** 教学依托的 `fde-scope` 代码在仓库里，不是 PPT——学员可以自己读实现。
5. **工业场景纵深。** 7 个工业门禁（`site_survey` / `fat_sat` / `functional_safety` / `conformity` /
   `works_council` / `air_gap` / `shift_handover`）在上表所有竞品里**没有一个覆盖**。
6. **把诚实当评分维度。** "诚实标注"得 0 分**一票否决**；用真实客户数据练习**一票否决**（[`03`](03-评估体系与通关门禁.md) §4、§8）。
   竞品普遍不惩罚夸大，我们直接把夸大判死。
7. **课程自身可复制。** 25 份文档 = 一整套可开办的教案包（讲师手册 / 运营手册 / 指标复盘 / 剧本案例库 / 模板库）。
   多数课程是黑盒交付，我们连"怎么开第二期"都给了。
8. **与官办项目同频而非对立。** 官办解决"认知与布局"（企业负责人），我们解决"手上会不会做"（工程师）——
   可与政府 / 协会 / 企业大学的项目**串成一条线**（§4.3）。

   那是"接下来 90 天自己走"，不是"本课改成了 4 个月"。
2. **无第三方认证。** 我们发的是本课证书 + 作品集评级。对照 ADaSci / GSDC / 工信部教育与考试中心 / 大连理工大学。
   雇主认不认，取决于学员能否用作品集自证。**不能拿"认证"当卖点。**
   想叠加第三方认证的三条路径与顺序见 [`15`](15-公信力与结果度量.md) §2；注意"教你考证"和"发证"是两件事。
3. **没有真实客户项目。** 全部为虚构案例（[`07`](07-实战剧本与案例库.md)）——这是"真实数据禁入"规则的代价。
   只有企业内训形态 C 才可能用客户自己的脱敏场景；加档形态 D 把这条做成了产品（[`14`](14-课后纵深与影子项目.md) §3），
   代价是**每期最多 3 人**、导师 ≤1:3、产出脱敏双签。
4. **没有就业服务。** 对照职坐标含猎头服务、FDE Academy 有招聘池。我们**不承诺就业、不承诺收入**（[`10`](10-变现路径与结营包.md) §8）。
   §9.1 的求职包与 §9.2 的内推池是**学员之间的互助**，不是我们的业务，也不收费。
5. **没有学员结果数据。** 目前没有历史班级的完课率 / NPS / 薪资样本；
   [`09`](09-运营指标与复盘.md) 里的指标线是**设计推导的基线，不是实测**。第一期的数据出来之前，这一项只能空着。
   [`15`](15-公信力与结果度量.md) §3 定了要收哪五项、§4 是待填的表、§5 是补齐清单——**表是空的，这是故意的**。
6. **价格不透明。** ~~按 [`04`](04-交付实施手册.md) §1.1 我们只给算法不给数字~~
   → 现在 [`04`](04-交付实施手册.md) §1.2 公开四档的**包含项与不包含项**，且 **L0 = ¥0 永久免费可以写进招生页**。

   所以这条只是部分补齐——**在比价场景仍是实打实的劣势**。
7. **工业纵深未经教学验证。** 7 个工业门禁是工具已有能力，但作为**课程内容**还没在真实班级跑过。
   [`15`](15-公信力与结果度量.md) §4 给它留了一行「工业纵深验证」，**空着到有班级为止**。
8. **交付人力重。** 需要试讲 ≥8/10 的讲师 + 1 : 15–20 的助教配比（[`04`](04-交付实施手册.md) §3、§7），
   自助开班门槛不低。§3.1 把助教拆成三级阶梯、列了四条减人手段——
   省的是**重复劳动，不是判断**，所以门槛降了但没消失。
9. **仅中文。** 课文为中文母稿；英文页面只译壳与章节名，**不译正文**（页面已明说"served as authored"）。
   [`en/README.md`](en/README.md) 提供英文快速入门（语言策略 / 8 天弧线 / 零 key 命令 / 诚实边界 / L0–L3），
   并用一整节列出**仍缺什么**——包括"课堂产出物本身是中文优先"。**快速入门不等于能上课。**
10. **国内市场也不只我们一家在讲。** 国内官办与商业培训已在快速铺开（§4.3、§4.4），
