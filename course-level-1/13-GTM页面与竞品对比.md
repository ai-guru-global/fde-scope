## 1. GTM 页（可直接粘贴）

### 1.1 一句话

> **这门课不解释 FDE，只炼金**——8 天，把 4 区 18 阶段的交付链路亲手走一遍，带走 8 件拿得出手的产出。

### 1.2 电梯稿（30 秒版）

```
市面上的 FDE 内容大多停在"概念解释"：FDE 是 Palantir 发明的、薪资很高、要懂技术又懂业务。
这些话没错，但解释不等于会用。

这门课用 8 天，让你亲手跑通一条完整的交付链路：
定边界 → 接数据 → 造语料 → 验证评估 → 运维化 → 交接沉淀 → 变现。

每天一道门禁，每天交一件老板和客户看得懂的产出。
第 8 天你手里不是笔记，是一套作品集，和一套话术。

不需要会写 Python，不需要 API key，也不需要换掉你现在用的工具。
```

### 1.3 三条卖点（每条都能当场验证）

1. **门禁是工程，不是清单。** 通关不是"看完了、考过了"，而是产出物过机器校验 + 讲师按量表打分。
   线上可当场演示：推进阶段时门禁**实时复评**，条件不满足就 `blocked`——不是靠自觉。
2. **零门槛、零 key。** 全链路核心证据不需要 API key、不需要 Docker、不需要 GPU，本机可跑；
   LLM 只是**可选加速**（关掉它整条链路照样走通）。对照：多数认证课要求 Python / 云基础先修。
3. **交出去的是作品集，不是结业证。** 8 件产出里有 Runbook、SLO 卡、值班交接卡、交接包——
   是接手的人真正要读的东西，不是"我学过"的证明。

> 三条都能被验证，而"验证方式"本身写进了课程： [`03`](03-评估体系与通关门禁.md) §4 评分量表、[`11`](11-工具与环境准备.md) §4.1 无 key 路径。

### 1.4 时间承诺（只说能核对的口径）

以 [`02`](02-逐日教学大纲.md) 的逐日时长为准（可逐条核对）：

| 天 | 投入 | 形态 |
|---|---|---|
| **D1 入门日** | **6 小时**（上午 3h + 下午 3h） | 线上直播 |
| **D2–D8**（每天） | **直播 90 分钟 + 自练 45 分钟** = 2.25 小时 | 直播 + 任务卡 |
| **整期合计** | **约 22 小时** | 8 天 |

排期与形态（连续 8 天 / 隔天 2 周 / 4 周自学 / 企业 3 天压缩）→ [`04`](04-交付实施手册.md) §2。

> ✅ **口径已统一**：早期 [`README`](README.md) 开头的"16–20 小时"是按均值粗估的口径，
> 现已改为与 `02` 一致的**约 22 小时**（D1 = 6 小时 + D2–D8 每天 2.25 小时）。
> 对外一律用本表的逐日口径——它能被逐条核对，而"16–20 小时"不能。

## 2. 适合谁 / 不适合谁

| 适合 | 不适合 |
|---|---|
| 刚入职 / 即将入职的 FDE、交付工程师（企业内训尤佳） | 想学模型训练、微调、算法竞赛的人 |

## 3. 学完拿走什么

**8 件产出（作品集）**：迷你链路证据 + 世界观 → 客户委托单 → 数据体检报告 → 语料报告 + 话术
→ Demo + bad case → Runbook + SLO + 值班交接卡 → 交接包 + 技能卡 → 作品集三套包装。

**9 道门禁（G0–G8）**：每道门禁 = 产出物 + 证据 + 讲师按 [`03`](03-评估体系与通关门禁.md) §4 量表打分；
**"诚实标注"得 0 分一票否决**，**用真实客户数据练习也一票否决**（作品失效 + 证书取消）。

**结业等级**：A / B / C 三档，按产出完整度与平均分评定，标准见 [`03`](03-评估体系与通关门禁.md) §6。

## 4. 横向对比

### 4.1 用这五个维度比

选维度比"比谁家内容多"有用。买 FDE 课的人真正要判断的是这五件事：

1. **投入**——能不能排进我的日程（几小时 vs 几个月）
2. **动手程度**——听讲 / 看视频 / 交作业 / **亲手跑通一条链路**
3. **产出物**——学完手里有什么（笔记？证书？能演示的东西？）
4. **评估方式**——怎么证明学会了（看完？考试？**产出过校验**？）
5. **背书**——发不发第三方证书、雇主认不认

外加一个价格维度，因为它是唯一的硬数字。

**这次取证新增的七条读法**（都不是 §4.2 原有结论）：

1. **两个新对手进表，各占一个我们最难打的位。** `Ontology University` 教的是 **Palantir Foundry + AIP 本尊平台**——这个角色就是在 Palantir 发明的，我们讲方法论、平台开源可审计，**在它面前没有"平台纵深"可讲**（同题对手不止它一家：`metriqacademy.com/courses/fde-palantir` 也在教 Foundry 版 FDE，**价格与大纲本次未取回**，§8 #33）；`Scaler` 用**约 12 个月 + 一个贯穿 14 个模块的客户项目**压我们的"8 天"，而"一个客户项目跑到底"恰好是 [`14`](14-课后纵深与影子项目.md) §3 形态 D 的主张——**我们把它做成加档，它把它做成主课**（对应 §6 #1、#3）。
2. **"门禁"不再是我们的独占词。** DeVenture 官方页明写 **"5 cumulative client acceptance gates"**。所以 §5 第 1 条的口径必须收窄：**我们独有的不是"有没有门禁"，而是"门禁对产出物机器判分、不满足就拒绝推进"**（[`03`](03-评估体系与通关门禁.md) §1.1）——DeVenture 那 5 个是**客户验收**口径，不是判分口径；但招生时**不能再简单说"别人没有门禁"**。
3. **技术栈宽度是真实短板，不是修辞谦虚。** ADaSci 一门 30 小时的课就点名 LangGraph / CrewAI / PydanticAI / MEM0 / Kubernetes / Jenkins / Trivy / Arize Phoenix / STRIDE / C4，Scaler 教到 Kafka，Maven 教到 vLLM 与 MCP。本课全文对其中多数名字**命中 0**（可复现，见 §6 #13）。
4. **两处源间冲突，这次拿到了判定依据。** ⚠ **GSDC 模块数**：官方页逐条列出了 **9 个模块名**（官方页面原文），而 AIM 榜单写的 "13 modules" 与 **NovelVista 官方页的 13 模块**内容一致——**很可能是媒体把两家写串**。仍按官网 9 为准；"写串"只是解释假设，**不得当结论对外引用**。⚠ **NovelVista 形式**：§4.2 那行记的是"80 小时 · 直播"（80h 出自 AIM，媒体转述），本次官网取回为"在线自定进度 + 终身回看"且**页面没有出现 80 小时**——两个口径都留着，但**对外别说它是直播课**。
5. **Maven Bootcamp 的价格与时长有了官方值**（US$2,500 / 6 周窗口 / 10 次直播）。§4.2 那行"4 周 · 未取回"是 **2026-09-30 看到的页面状态**，**保留不改**——改掉就丢了"我们什么时候看到什么"这条链；对外引用**用本节口径并注明 2026-10-08**。
6. **一句话可用的对比**（有出处、可核对）：*"付费课的目录是**一条技术栈**（LangGraph、K8s、Trivy、Kafka、Foundry），我们 8 天的目录是**一条交付链路**（18 阶段 / 10 个门禁 / 8 件产出）——比之前要先说清我们在比哪一件。"*
7. **"FDE"这个词本身正在被平台方产品化。** Palantir 官方文档存在一个名为 **AI FDE** 的条目，搜索摘要口径是
   "the AI-powered forward deployed engineer, is an interactive agent that operates Foundry for you through
   conversational commands"（档位＝**搜索摘要**，正文**未取回**，见 §8 #34）。
   对我们的说法有两层影响：**①** 招生页里"FDE = 把 AI 送进客户生产环境的人"这个定义要留得住，

## 5. 优势（诚实版，每条落在一个可核对的事实上）

1. **门禁是工程，不是清单。** 通关靠产出物过校验，不靠自觉或选择题。可现场演示
   `engage advance` 被 `blocked`。[`03`](03-评估体系与通关门禁.md) §1.1
   > ⚠ **对比口径（2026-10-08 起必须照这句说）**：竞品**也有**门禁——DeVenture 官方页明写
   > "5 cumulative client acceptance gates"（§4.2.1 第 5 行 / §8 #28）。
   > 我们的独有点是**判分方式**：**对产出物机器判分、不满足就拒绝推进**，而 DeVenture 那 5 个是**客户验收**口径。
   > 招生页上**不许写"别人没有门禁"**，要写"别人的门禁是验收清单，我们的门禁会拒绝你推进下一步，而且当场能演示"。
2. **产出覆盖完整交付链，不是单点技能。** 8 件里有 Runbook、SLO 卡、值班交接卡、交接包、合规六件套——
   多数竞品的产出物是**一个能跑的系统**。（⚠ 2026-10-08 修正：**不能说"别人止步于 demo"**——
   DeVenture 有 Capstone"Enterprise Deployment Project"、Scaler 用一条贯穿 14 个模块的客户项目，
   见 §4.2.1。差别在**交付链上留没留纸**：我们的 8 件里有运维、值班交接、合规与交接包这几类**客户方要存档的东西**，
   取回的 8 份大纲里只有 GSDC 与 DeVenture 写到部署与安全合规模块，**没有一家在页面上列出上面那几类存档产出物**。）
3. **零门槛、零 key、不换工具。** 不需要 Python，不需要 API key，不要求替换你现有的编码 / 办公 Agent；
   课程只叠"流程与门禁层"。[`01`](01-课程设计说明书.md) §6.4、[`11`](11-工具与环境准备.md) §4.1
4. **平台层开源可审计。** 教学依托的 `fde-scope` 代码在仓库里，不是 PPT——学员可以自己读实现。
5. **工业场景纵深。** 7 个工业门禁（`site_survey` / `fat_sat` / `functional_safety` / `conformity` /
   `works_council` / `air_gap` / `shift_handover`）在上表所有竞品里**没有一个覆盖**。
   > ⚠ **这句在 2026-10-08 之后要说得更准，两处边界**：
   > **① 范围**：结论成立的范围是"**我们查过的这些家**"——§4.2.1 的 8 家付费课拿到了大纲级页面，
   > 而 §4.3 官办与 §4.4 商业侧**多数机构的大纲本次未取回**（表中多为"未列明"）。
   > 对外可以说"在我们逐条查证过的课程里没有一个覆盖"，**不能说"全世界没人教工业 FDE"**——
   > 后者正是 [`08`](08-运营手册.md) §2.1 禁用句清单要钉死的那类最高级表述。
   > **② 别把两类"安全合规"混成一类**：ADaSci 大纲点名的 OWASP / STRIDE / Trivy 是**软件安全**（§4.2.1 第 1 行），
   > 与 `functional_safety`（ISO 26262 那一类）**不是一回事**；招生页上被追问"他们不是也讲安全吗"时，
   > 答案就落在这一句区分上（[`03`](03-评估体系与通关门禁.md) §1.1 的门禁定义）。
   > **③ 我们自己也要照照镜子**：GMP 与 医疗器械 在本课正文**同样是 0 命中**（§6 #13 实测）——
   > 我们的工业纵深是**门禁维度有**，行业合规条文**没进课文**，这条 §6 #7 已登记为结构性缺口。
6. **把诚实当评分维度。** "诚实标注"得 0 分**一票否决**；用真实客户数据练习**一票否决**（[`03`](03-评估体系与通关门禁.md) §4、§8）。
   竞品普遍不惩罚夸大，我们直接把夸大判死。
7. **课程自身可复制。** 26 份文档 = 一整套可开办的教案包（讲师手册 / 运营手册 / 指标复盘 / 剧本案例库 / 模板库）。
   多数课程是黑盒交付，我们连"怎么开第二期"都给了。
8. **与官办项目同频而非对立。** 官办解决"认知与布局"（企业负责人），我们解决"手上会不会做"（工程师）——
   可与政府 / 协会 / 企业大学的项目**串成一条线**（§4.3）。
9. **免费对手也敢列进对比表。** §4.6 把 GitHub 上**我们检索到的池子里星标最高的**开源 FDE 物料摊开比
   （"星标最高"的范围是 `24` §1 那三次检索的 `total_count`，**不是"全网最高"**），
   并且把"我们输在哪"写成了一张 7 行表（附卷 [`24`](24-开源对标与来源清单.md) §6）——
   **本次取回的 8 家付费课页面里，没有一家有对应物**（它们只有卖点清单，§4.2.1）：
   短板表可以造假，**每条都能重跑的 `gh api` / `grep` 命令不行**，所以这张表是"不吹牛"的**物证而不是话术**。
   可核对：每个开源仓库的星标 / 文件数都能用附卷给出的 `gh api` 一条命令重跑，
   §6 #13 的技术栈命中数能用本节那段 `grep` 重跑（§8 #22 / #35）。
