# 08 · 运营手册

> 面向运营负责人与班主任：**招生 → 开营 → 日常 → 结营 → 复训**的全流程 SOP。
> 交付执行（排期/人员/应急）见 [`04-交付实施手册.md`](04-交付实施手册.md)；
> 指标与复盘模板见 [`09-运营指标与复盘.md`](09-运营指标与复盘.md)。

## 1. 运营角色与总时间轴

| 角色 | 一句话职责 |
|---|---|
| 运营负责人 | 招生漏斗、社群、激励、结营组织；对完课率与 NPS 负责 |
| 班主任 | 每日节奏执行（任务卡/催交/门禁榜）、掉队干预、学员关系 |
| 助教（教学侧） | 答疑、门禁初审、角色扮演——管理规则见 §8 |

**一期总时间轴**（标准 8 天案；压缩案见 `04` §2）：

```
T-14 招生启动 → T-7 报名截止 → T-3 分班建群 → T-1 开营前任务
D1–D8 每日运营节奏（§4）→ D+1 结营问卷 → D+7 变现回访 → D+30 期报复盘
```

## 2. 招生

### 2.1 渠道与文案

| 渠道 | 侧重 | 备注 |
|---|---|---|
| 公众号 / 社群 | 世界观长文 + 学员产出实拍 | 用真实作品集（须书面授权，见 `03` §8） |
| 短视频 | 60 秒演示：一条命令跑通 corpus | 用虚构案例数据，不露真实客户 |
| 合作渠道（企业/猎头/社区） | 企业内训对接 | 转 `04` 形态 C |

**文案三要三不要**：

- ✅ 要讲**产出**："8 天带走 8 件可展示的交付物"
- ✅ 要讲**诚实边界**："训练能力与作品集，不承诺就业、不承诺收入"
- ✅ 要讲**零门槛**："不需要会 Python，不需要 API key"
- ❌ 不要用"包就业 / 保涨薪 / 学完年薪 X 万"（合规红线，见 §11）
- ❌ 不要贬低学员现状（"还在做螺丝钉？"）——用中立的问题陈述替代
- ❌ 不要在营销素材里出现任何真实客户名/真实数据

**禁用句清单（原句 → 为什么 → 换成什么）**

| # | ❌ 禁用句（及同类变体） | 为什么禁 | ✅ 换成 |
|---|---|---|---|
| 1 | "包就业 / 保涨薪 / 学完年薪 X 万" | 合规红线，本课不提供就业与收入承诺（[`10`](10-变现路径与结营包.md) §8、§11） | "训练能力与作品集；就业与收入**不承诺、不预测**" |
| 2 | "国内首个 / 全国唯一 / 行业第一" | 官办与商业培训已在快速铺开，"首个"**很快会过期**，且无法自证（[`13`](13-GTM页面与竞品对比.md) §6 #10） | 用**可核对的特点**替代排名：零 key 可跑、8 件产出、门禁制（`13` §1） |
| 3 | "学完就能考 CFDE / 包过认证班 / 考完送证书" | 我们**没考过**、与发证方**无合作**（[`15`](15-公信力与结果度量.md) §2.3） | 照 [`15`](15-公信力与结果度量.md) §2.1–§2.2 讲"有哪三条路径、怎么叠加"，明说**不代报名、不返佣** |
| 4 | "结业送工信部 / XX 大学证书" | 证书必须**谁的渠道写谁的名**，错渠道即虚假陈述（[`15`](15-公信力与结果度量.md) §2.2 例） | 只写实际颁发的那张（本课证书 + 编号规则，[`15`](15-公信力与结果度量.md) §1.2） |
| 5 | "8 天顶 4 个月 / 8 天达到资深 / 学时顶 XX 学时" | 学时不是可比单位，且我们主动认账深度有限（[`04`](04-交付实施手册.md) §1.2 读表纪律 2） | "8 天学到**能独立跑通一条链路 + 手里有 8 件产出**；资深要靠真实项目里练" |
| 6 | "FDE 人才缺口 XX 万 / 平均月薪 XX"（无来源） | 无出处数字一律禁用（[`10`](10-变现路径与结营包.md) §8） | 引用四要素：`<区间> ｜ 来源 ｜ 采集日期 ｜ 口径`；匿名爆料不做唯一来源 |
| 7 | "原价 ¥X 现价 ¥Y / 最后 3 个名额 / 今晚涨价" | 虚构划线价与无依据稀缺（[`04`](04-交付实施手册.md) §1.2 三条禁止） | 写本期班型与**人数上限**（"最多 30 人"）+ 价格的构成口径 |
| 8 | "包学包会 / 学不会全额退"（无书面条款） | 承诺必须有可执行条款与责任主体 | 只承诺**已写进文档**的东西：补交与复训（`03`/`08` §9）、申诉三步（§10） |
| 9 | "学员 XX 学完涨薪 X%"（个案当统计） | 个案不等于比率；对外数字必须带分母与样本量（[`15`](15-公信力与结果度量.md) §3.3） | 只引用 [`15`](15-公信力与结果度量.md) §4.1 的结果度量表，且**带分母**；未达样本量只做定性 |
| 10 | 素材里出现真实客户名 / 真实数据 / PII | 数据红线（§11） | 一律用虚构案例库（[`07`](07-实战剧本与案例库.md)）；真实作品集须本人**书面授权**（`03` §8） |

**怎么用这份清单**：招生文案发布前，用 `Ctrl+F` 搜关键词——`包`、`保`、`首个`、`唯一`、`原价`、`名额`、`缺口`、`年薪`——
命中任一条就改；**改不了就不发**（宁缺一次曝光，不欠一次承诺）。

> 这份清单与 [`10`](10-变现路径与结营包.md) §8 查证纪律、[`13`](13-GTM页面与竞品对比.md) §6 劣势认账、
> [`15`](15-公信力与结果度量.md) §2/§3 发布纪律，是**同一套纪律的四个切片**；改一处要对齐另外三处。

### 2.2 报名筛选（3 个问题，报名表内嵌）

1. "你目前的工作/学习状态是？"（分人设 A/B/C，见 `01` §2）
2. "接下来 8 天，你每天能稳定投入 2 小时吗？"（选"不能"→ 引导自学版 `04` 形态 B）
3. "你更想要什么：听概念 / 动手交付？"（选前者 → 明确告知本课以动手为主）

**分班规则**（T-3 执行，按自评雷达）：强弱搭配结对；每 15–20 人配 1 助教；
**同一个组的学员尽量来自不同行业**（扩大互评视角）。

## 3. 开营（T-3 → D1）

### T-3 · 建群与预热

- [ ] 建群、置顶五件套：**任务卡入口 / 答疑时段 / 群规（§5）/ 诚实边界声明 / 提交入口**
- [ ] 发布《学员手册》[`06`](06-学员手册与作业包.md)，要求开营前读完 §0–§2
- [ ] 发放自评雷达（4 维 1–5 分）+ 学习契约（`06` §1）

### T-1 · 开营前任务（环境）

- [ ] 发布环境准备指引 → [`11`](11-工具与环境准备.md)；群内"装好了"接龙
- [ ] 统计未装好人数；>20% 报错 → 触发 `04` §6 的"环境急诊室"预案
- [ ] 公布分班与结对名单、助教分工与答疑排班

### D1 · 开营仪式（30 min，运营主持 + 讲师压轴）

```
1. 运营（10 min）：课程契约、门禁制、补交规则、群规、诚实边界
2. 学员（15 min）：30 秒自我介绍（我是谁 + 我最怕现场哪件事）
3. 讲师（5 min）：一句话点燃 + 预告今晚就要交第一件产出
```

## 4. 每日运营节奏 SOP

> 与 `02` 附录、`04` §5 同一套节奏；本节的"运营动作"列是班主任的执行清单。

| 时间 | 动作 | 负责人 | 验收 |
|---|---|---|---|
| 08:30 | 发布**门禁通过榜**（昨日）+ 催未通过者 | 班主任 | 榜单+@未通过者 |
| 09:30 | 发布**当日任务卡**（`06` 对应日）+ 门禁检查项 | 班主任 | 群消息 + 置顶更新 |
| 直播中 | 记录"停车场"问题（讲师转交） | 助教 | 问题清单 |
| 直播后 30 min | 上传录播 + 讲义 + 命令清单 | 助教 | 群公告链接 |
| 13:00 | 午间"昨日优秀作品"展示（附点评一句话） | 班主任 | 需学员授权（`03` §8） |
| 19:00–20:00 | 集中答疑窗口（语音/直播） | 助教轮值 | 响应率 100% |
| 21:00 | 提交截止前 30 min 提醒（仅提醒未交者） | 班主任 | 私聊 |
| 21:30 | 催交 + 当日优秀作品提名（收集） | 班主任 | 提名 ≥1 件 |
| 22:00 | 汇总：当日提交率、答疑遗留问题 | 班主任 | 记入 `09` 看板 |

**每日运营三件必做**：①任务卡准时（误差 ≤10 min）②答疑响应 100% ③掉队者当天私聊（不公开点名）。

## 5. 社群 SOP

### 5.1 群规（置顶，开营日发布）

1. 不发广告、不拉人、不私加好友推销。
2. 提问用四要素模板（`06` §7）；**报错先附截图**。
3. 真实客户名与 PII 一律不进群（红线，见 §11）。
4. 作业不抄袭；被发现抄模板不改者，公开提醒一次，二次记录。
5. 友善：不嘲笑小白问题——"这是 FDE 现场最贵的品质"。

### 5.2 话题节奏（保持群活性的每日栏目）

| 栏目 | 时间 | 内容 |
|---|---|---|
| #今日一句 | 09:00 | 讲师金句（`05` §7 金句库） |
| #踩坑接龙 | 全天 | 学员贴一个报错 + 怎么解的；解对的加分 |
| #优秀作品 | 13:00 | 昨日最佳产出（授权后展示） |
| #凌晨2点 | 21:00 | 预告/复盘 D6 的盲测梗，制造记忆点 |

### 5.3 禁止与升级

- 出现争执：班主任先私聊双方 → 群里发一句"已处理，回归学习"（不辩论、不站队）。
- 出现广告/PII：**立即撤回 + 私聊警告**；PII 情形记录到合规日志（§11）。

## 6. 激励体系（积分 / 徽章 / 排行）

> 设计原则：**奖励证据与互助，不奖励活跃度**——否则会催生"水群"。

### 6.1 积分规则

| 事件 | 积分 | 说明 |
|---|---|---|
| 门禁按时通过（无补交） | +10 | 每天最多一次 |
| 24h 内补交通过 | +5 | 留痕但仍有分 |
| 助人解答被采纳 | +5 | 由被助者或助教确认 |
| 结对互评（有效：找出对方 ≥1 个真实问题） | +5 | 每天一次 |
| 优秀作品（讲师提名） | +15 | 每天 ≤2 件 |
| 主动披露自己产出中的错误/不确定项 | +5 | **诚实加分项**（课程独有） |
| 代做 / 伪造证据 | 清当件积分 | 并触发 `03` §7 违规处理 |

### 6.2 徽章

| 徽章 | 条件 |
|---|---|
| 🎯 过闸人 | 连续 3 天门禁一次通过 |
| 🧪 淘金者 | D4 语料话术被评为零术语且数字链完整 |
| 🛡️ 诚实者 | 累计 3 次主动披露不确定项 |
| 🤝 摆渡人 | 累计助人 ≥5 次被采纳 |
| 🏁 完赛者 | G8 结业（按 `03` §6 等级加注 A/B/C） |

### 6.3 排行与奖品

- 排行榜**只展示前 10**（避免公开倒数）；个人分数私聊可查。
- 奖池建议：A 级作品集定制点评 / 与讲师 1v1 职业咨询 30 min / 下期助教直通面试。
- **禁止**现金化排名（防止刷分）。

## 7. 三级干预（掉队处理）★

> 被 `04` §6、`05` §6 引用。触发信号：**连续 2 天未提交门禁**，或**答疑窗口连续 2 次未现身且群内无互动**。

```
第一级 · 私聊唤醒（班主任，触发后 24h 内）
  - 一句话确认状态："你还好吗？卡在哪一步？"
  - 给出**最小可交付版本**（Mini 版）：如 D3 只交"字段表 + 一个风险"也算过
  - 若因工作/家庭突发：启动"暂停键"——可申请把节奏切到自学版（`04` 形态 B）

第二级 · 助教 1v1（第一级后 48h 仍无产出）
  - 15 分钟共屏：当场陪跑一次任务卡，把卡点定位到"概念/工具/时间"哪一类
  - 定一个 24h 内的"复活交付"（一件比 Mini 还小的产出，重建动量）
  - 结果抄送讲师（进 `09` 掉队档）

第三级 · 讲师谈话（第二级后仍停滞，或学员主动求助）
  - 判断根因：目标错配（其实想学别的）→ 劝转班/退款；时间不可控 → 协商延期到下一期
  - 任何第三级处理都**私聊进行**，不上群、不点名（`05` §8 控场原则）
  - 记录"流失原因"分类，进 `09` 期报
```

**干预铁律**：宁可让学员"Mini 版通过"，也不让他掉出节奏——**连续性 > 完整性**。

## 8. 助教管理

| 环节 | 规则 |
|---|---|
| 招募 | 过 G8 的往期学员优先（A 级直通）；外部助教需通过"试扮演"（演 §4.2/§4.3 角色卡） |
| 培训 | 当一期"影子助教"（`04` §7）后上岗；发 [`05` §4 带教要点 + `07` 角色卡 + `03` 门禁判据] 三件套 |
| 排班 | 每日答疑窗口轮值（19:00–20:00）；角色扮演日（D5/D7）全员在线 |
| 质量 | 每周抽 3 条助教答疑评语，检查是否"给答案 vs 给方法"——**给方法**才合格 |
| 激励 | 按学员完课率 + 好评率给酬劳系数；优秀助教进讲师培养池 |
| 红线 | 助教不得私下接学员外包/私单（利益冲突）；不得泄露学员作品 |

## 10. 运营 FAQ

| 问题 | 处理 |
|---|---|
| 学员要求退款？ | 开营前：全额退；开营后 D1–D2：退 50%；D3 起不再退（可延期到下一期一次）。以招生页条款为准。 |
| 学员想插班？ | 仅允许 D2 前插入，且须先补 D1 录播 + G1；之后一律引导下一期。 |
| 学员要求换组/换案例？ | 允许一次（私聊班主任），避免"案例不合口味"成为掉队借口。 |
| 企业客户要开发票/对公？ | 转 `04` 形态 C 报价流程；发票信息收集表另附。 |
| 讲师和学员起冲突？ | 班主任先接住学员情绪，48h 内与讲师对齐；若属实，进期报改进项。 |
| 学员想退课但先要作品集？ | 按已完成的产出如实交付（作品集归学员，`03` §8），不设卡。 |
| 学员觉得被"判错"（门禁/评分不服）？ | **走申诉三步**：① 私聊班主任写清"哪一条 / 我认为应该是什么 / 证据"；② 24h 内由**未参与该次评分的人**（另一位助教或讲师）复核原件；③ 结果书面回执。**改判成立 → 更新成绩并进期报改进项；不成立 → 说明理由**。申诉不影响态度评分；对 G8 结业门结果仍有异议 → 班主任升级讲师，3 个工作日内终裁。 |
| 学员投诉讲师/助教（态度、迟到、歧视性言论）？ | 班主任**先接住情绪、不辩解**，24h 内独立记录事实与时间点；涉歧视/骚扰类**零容忍**——立即隔离当事双方、上报课程负责人，与当事人分开取证。处理过程不公开点名，结果告知投诉人。**投诉渠道始终开放**：班主任私聊 → 课程负责人 → （企业内训）客户 HR 对接人三级可达。 |

**申诉与投诉的共同纪律**：全程**书面留痕**（私聊记录/邮件），进合规日志（§11 第 5 条）；
**不得**在公开群讨论具体投诉内容，**不得**因申诉/投诉降低对学员的评价。

## 11. 合规与数据红线（运营视角）

1. **宣传口径**：不得承诺就业/收入；引用薪资数据必须带来源与日期（见 `10`）。
2. **学员数据**：报名信息仅用于课程运营；对外展示作品集需**书面授权**（`03` §8）。
3. **练习数据**：群内一旦出现真实客户名/PII——立即撤回 + 私聊 + 记录合规日志；
