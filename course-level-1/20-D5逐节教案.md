## 0. 今天的三条红线（全天不许破）

| # | 红线 | 怎么守 |
|---|---|---|
| 1 | 全天只出现 **3 个新概念**：**真实数据原型 · 评估指标（带业务口径）· bad case（改进抓手）** | 「准确率 / 召回 / F1 / 混淆矩阵 / 金标集 / 基线」一律进停车位（白板角落），课后答疑再讲。对客户说"**拿你们真实的 200 条单子试过，60% 能直接回**"，不说"F1 = 0.87"——**裸用"准确率"就在 [`12`](12-附录-术语表与模板库.md) §2.3 的禁用词表里** |
| 2 | **指标是地图，不是成绩单**——第一次跑难看是正常的；**不许为了好看换数据、换口径、删坏例** | 换一批好看的测试集 / 删掉失败样本 / 只贴平均分不挖坏例子 = **Demo-Debt**（[`12`](12-附录-术语表与模板库.md) §1.6 #4）的入场券。G5 ① 要求**同命令同结果**——你动一次口径，① 就是不过（[`03`](03-评估体系与通关门禁.md) §3） |
| 3 | **关键决策留人确认（HITL）必须写进方案**——被问到"答错了谁负责"不许用"我们模型很准"接 | **No HITL**（[`12`](12-附录-术语表与模板库.md) §1.6 #11）是反模式：今天演练的第一问就是它（[`07`](07-实战剧本与案例库.md) §3.4 第 1 问）。回答里没有 HITL 兜底设计 = **这一轮不通过**，当场补 |

**今天没有硬性休息**：D5 直播同样只有 90 分钟，中间不设休息点。
但 **S2 的"幕 3 全绿陷阱"** 是全天的天然停顿点——当学员发现"最差的 agent 也能拿满分卷"时，停 10 秒，让他们自己说一句感受，再往下走。

**为什么今天"最反直觉"**：前四天你都在做加法（接数据、造语料、写交付物），今天你要**给自己找茬**——
而且工具会**主动配合你骗自己**：假分数长得跟真分数一模一样，难看的话一句不说。
今天全天只有一个动作：**把"我觉得挺好的"换成"我怎么知道的"。**

> **今日产出物（🎯 产出 5）**：**四样东西**——
> ① **原型证据**：一个**能演示的原型**（≤2 分钟录屏，或现场演示）——跑在**真实数据原型**上（你们自己那批脏数据），不是策展测试集。
> ② **评估结果**：`eval --agent mock` 跑出来的报告（指标表 + Top bad case 类）。
> ③ **Top3 bad case**：每条含四要素——**现象 → 根因假设 → 下一步动作 → 预计改善**。
> ④ **一页"验证记录"**：含**被拒绝的需求**（[`12`](12-附录-术语表与模板库.md) §2.6 四行表）。
> **通关门禁 G5 原文**（[`03`](03-评估体系与通关门禁.md) §3）：
> ① 评估**可复现**（同命令同结果）② bad case Top3 每条含**"下一步动作"** ③ 有一页**"验证记录"**（含被拒绝的需求）
> —— **①② blocker；③ warning**。
> ⚠ 注意 ③ 只是 warning：它不拦你，但**答辩评分表里"边界感"一项看的就是它**（[`12`](12-附录-术语表与模板库.md) §2.6）。
> 真正会把你拦在门外的是 ②——**"只描述现象、不给下一步动作"** 的 bad case 清单，写得再漂亮也是 ② 不过。

## S1 · 回炉（0–10 min · 10 min）

**本节定位**：10 分钟干三件事——交出 D4 的账（门禁榜 + 1 优 1 劣），然后**打今天的预防针**，最后让每个人写下自己的"恐惧数字"。**不讲课，只讲评 + 提问。**

**一句话目标**（开场念）："昨天你们的语料报告我看了。今天我要先给你们打个预防针——**接下来你跑出来的指标，会比你想象的难看。这不是坏消息，这是它唯一的用处。**"

### 分钟级时间盒

| 分钟 | 动作 | 目的 |
|---|---|---|
| 0–3 | **G4 门禁榜**（通过 / 补交 / 未交 三个数字）+ 补交规则复述 | 让"过没过"变成公开事实 |
| 3–8 | **1 优 1 劣讲评**（都不点名） | 让"好长什么样"可复制，让"坑"提前暴露 |
| 8–10 | **预防针 + 写下"我最怕看到的数字"** | 把恐惧提前说出口，S2 才有冲突可收 |

### 讲稿要点

**① 0–3 min｜G4 门禁榜：三个数字 + 一条规则**

- 只念三个数：**通过 __ 人 / 补交 __ 人 / 未交 __ 人**（不念名字，名单课后私聊）
- 复述补交规则（[`03`](03-评估体系与通关门禁.md) §3 文末，全年**只讲这一次也要讲清**）：
  > "24 小时内补交 = **正常放行（标注"补交通过"）**；超过 24 小时 = **延期通过**，**作品集等级最高 B**；特殊情况走豁免，但豁免会**写进证书备注**。"
- 一句话收口：**"门禁不是考核，是防掉队。今天 D5 如果你缺东西，明天 D6 会直接卡住——因为你要给一个已经跑起来的东西写运维文档。"**

**② 3–8 min｜1 优 1 劣（都不点名）**

**优（要念出细节，让全班知道"好长什么样"）**——挑一份**数字链完整**的：

> "这份报告里写：'原始 20 行，淘汰 0 条，真实 20 + 合成 395 = 415，切分 332 / 41 / 42。'
> 然后它多写了一行——'**其中 test 42 条里真实样本为 0**'。
> 这一行是全班最值钱的一行。**没人问它，它自己说了。** 这就是 G5 要的东西：不是好看，是**可信**。"

**劣（不点名，讲模式）**——挑一份**只有结论没有出处**的：

> "另一份报告写：'语料质量良好，覆盖度达标，学员可直接用于训练。'
> 我拿红笔圈了三个词：**良好 / 达标 / 直接**。这三个词在这里都是**形容词**，不是**证据**。
> 我逐条问它出处，三条都指不出来——**指不出出处的数字 = G4 ① 不过**（[`12`](12-附录-术语表与模板库.md) 文末三条纪律 ①）。
> 今天 D5 是同一件事的升级版：**昨天你指不出语料的出处，今天你就要指不出指标的出处。**"

**③ 8–10 min｜预防针 + "我最怕看到的数字"**

念 [`05`](05-讲师手册.md) §4 D5 第 1 条（**原话**）：

> "**第一次评估指标难看是正常的——指标是地图，不是成绩单。**"

然后让每个人在群里打**一个数字或一句话**：**"今天我最怕看到的指标是什么？"**

**这个动作是本节的灵魂**：先落笔，后对照。S2 幕 3 结束时，会有人发现——**自己怕的那个数字，恰恰是全场唯一真的那个**。

- 右半屏：**今日路线**（S1→S6 六格，S2 那格画 6 个小圆点代表六幕）
- 白板角落（今天叫**停车位**）：画个框写"**准确率 · 召回 · F1 · 混淆矩阵 · 金标集**"——今天冒出来的术语一律扔这儿

### 互动设计

- 群接龙：**"我最怕看到的数字"**——三条示例先给出去降低门槛：
  - "我怕 `intent_accuracy` 出来 0.000"（正常反应，S2 幕 2 会告诉他为什么可能"假 0"）
  - "我怕客户问我这数怎么来的，我答不上"（**这个才是真问题**）
  - "我怕结果是好的，但我知道那是假的"（最成熟的一种——今天全场就练这个）
- 讲师**不点评任何一条**，只说："记住你写的那句。四十分钟后我们回来对。"

### 常见错误与纠偏

| 错误 | 纠偏 |
|---|---|
| 讲师把 G4 未交名单念出来 | 只说数字不说名字——安全底线，掉队者课后私聊 |
| 预防针说成"今天会很难" | 措辞必须是 **"难看是正常的，难看有用"**——不是难度警告，是**心理授权** |
| 学员问"那指标好看怎么办" | 反问："**如果它好看，你先告诉我它测的是不是你以为的那个东西。**" 这就是 S2 幕 2 的引子 |

### 承接语（最后 30 秒）

> "你们每个人手里现在都有一个数字。四十分钟后，我会当场跑六遍。
> 其中一遍会让你发现自己写的那个数**没那么可怕**；另外一遍会让你发现——**它压根没在测你以为它在测的东西**。
> 走。"

### 学员笔记要点

- G4 门禁榜数字 + 补交规则（24h 内=正常放行 / 逾期=延期通过（封顶 B）/ 豁免进证书）
- "**指标是地图，不是成绩单**"（[`05`](05-讲师手册.md) §4 D5 第 1 条）
- 我写下的"最怕看到的数字"：____________
- 一句待验证的话：**"如果指标好看，先问它测的是不是我以为的东西。"**

## S2 · 讲与演（10–35 min · 25 min）

**本节定位**：25 分钟连续跑**六幕**，六幕围绕一句话——**"我怎么知道它行？"** 全程零 key、零网络，`.venv/bin/python -m fde_scope.cli` 真跑真投屏。

**一句话目标**（开场念）："今天我不讲道理，我讲**证据**。接下来六遍命令，每一遍都会教你们一件事——**工具不会主动骗你，但它也不会主动拦你。**"

### 分钟级时间盒

| 分钟 | 幕 | 动作 | 这一幕教什么 |
|---|---|---|---|
| 10–14 | **幕 1** | `eval` 版本 A（5 行 · 无 `expected_category`） | 全绿的表长什么样；**谁是表里唯一的真信号** |
| 14–19 | **幕 2** | `eval` 版本 B（含 `expected_category`） | `intent_accuracy` **恒 0.000 的假分数** |
| 19–23 | **幕 3** | `--accuracy 0.9` vs `--accuracy 0.0`（逐字节对拍） | **最差的 agent 也能拿满分卷**——今天最重要的一幕 |
| 23–25.5 | **幕 4** | 同一命令连跑 3 次 | G5 ①"可复现"长什么样（同命令同结果） |
| 25.5–31 | **幕 5** | `kpi`：平均值 → 逐工位拆解 | **平均分掩盖 bad case**；0.0 有两种含义 |
| 31–35 | **幕 6** | `gate check` + G5 条文 | **没有"证据门"这个工具**——G5 是人工判的 |

### 讲稿要点

**① 幕 1（10–14 min）｜全绿的表，和唯一的真信号**

先跑，不解释。让表格自己说话：

```
┏━━━━━━━━━━━━━━━━━━━━━━━┳━━━━━━━┳━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃ metric                ┃ value ┃ label                            ┃
┡━━━━━━━━━━━━━━━━━━━━━━━╇━━━━━━━╇━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┩
│ corpus_coverage       │ 0.000 │ 意图覆盖率（0-1）                │
│ corpus_quality_avg    │ 0.000 │ 平均质量分（1-5）                │
│ corpus_diversity      │ 0.000 │ 语义多样性指数                   │
│ intent_accuracy       │ 1.000 │ 意图识别准确率                   │
│ reply_adoption_rate   │ 1.000 │ 回复采纳率（人工未修改直接使用） │
│ escalation_rate       │ 0.200 │ 人工升级率（越低越好）           │
│ first_contact_resolve │ 1.000 │ 首次接触解决率                   │
│ avg_handle_time       │ 0.000 │ 平均处理时长（对比人工基线）     │
│ customer_satisfaction │ 3.000 │ 客户满意度（CSAT）               │
│ cost_per_ticket       │ 1.000 │ 单工单成本                       │
└───────────────────────┴───────┴──────────────────────────────────┘
```

停 10 秒，问全班一句：**"这张表里，哪个数字是真的？"**

然后逐个点掉（这是今天的第一次"祛魅"）：

| 你看到 | 你以为是 | 它其实是 |
|---|---|---|
| `intent_accuracy 1.000` | "意图识别 100% 准" | **没测**——你没填 `expected_category`，这一行按"无信号 = 不扣分"记 1.0（[`12`](12-附录-术语表与模板库.md) §2.4「读表前必看」） |
| `reply_adoption_rate 1.000` | "回复 100% 被采纳" | **没测**——`adopted` 没数据，默认 1.000 |
| `first_contact_resolve 1.000` | "100% 一次解决" | **没测**——默认值就是 `true` |
| `avg_handle_time 0.000` | "快到 0 秒" | **没测**——没有一条记了时长；`cost_per_ticket 1.000` 同理（与人工基线持平 = 没数据时的中性值） |
| `customer_satisfaction 3.000` | "满意度 3 分" | **没测**——1–5 分制的**中性中点** |
| `corpus_* 0.000` ×3 | "语料很差" | **没接语料报告**——`eval` 不自带语料维度（这是 D4 的活） |
| **`escalation_rate 0.200`** | "20% 的升级率" | ✅ **真的**——`escalated: true` 是你在数据里**真写的**：5 条里 1 条 |

> "看清楚了吗？**十行里九行是填充物，只有一行是真的。**
> 而这一行——**升级率高是坏消息**（越低越好）。所以今天第一次跑，唯一的真信号是一条**坏消息**。
> 这不是 bug。这是这份表**唯一诚实的部分**。"

**② 幕 2（14–19 min）｜`expected_category`：那个让你得 0.000 的字段**

"昨天有人问我：'既然 `expected_category` 是标准答案，我填上不就更准了吗？'
来，我们填上。"

跑版本 B（前 4 行**加上** `expected_category`），结果：

```
│ intent_accuracy       │ 0.000 │ 意图识别准确率                   │
│ escalation_rate       │ 0.250 │ 人工升级率（越低越好）           │
```

> "`intent_accuracy` 从 1.000 掉到 **0.000**。滑天下之大稽——**我给它标准答案，它反而变笨了？**
> 不是变笨。是**判分口径**变了（[`12`](12-附录-术语表与模板库.md) §2.4）：填了 `expected_category` 之后，
> 判分规则变成**子串匹配**——它会去 agent 的回复里**找有没有"退款售后"这四个字**（`fde_scope/eval/metrics.py` `score_intent_accuracy`）。
> 而 mock 的回复是 `已为您处理：我要退货，怎么操作？…（mock 回复）`——**它只复读你的问题，从来不报类别名。**
> 所以在**真模型**上，版本 B 是必须的；在 **mock** 上，版本 B 只会给你一个 **0.000 的假分数**。"

收口（这句要慢）：

> "**两个版本，一个给 mock，一个给真模型。复制错了，你得到的是一个看起来像'系统很烂'、实际上什么也没测的数字。**
> 这也正是 D4 那条纪律的第二次现身：**指不出出处的数字不要写。** 现在你知道'出处'有两个方向——**数据从哪来**，还有**这个数是怎么算出来的**。"

**③ 幕 3（19–23 min）｜全绿陷阱：把 agent 调到最差，表格一格不动**

> "接下来这一幕是今天全场最重要的一幕。我要把 mock 调到**最差**——`--accuracy 0.0`，意思是**它对每一条都回答'抱歉，我不太理解您的问题'**。"

先跑 `--accuracy 0.9`（默认），再跑 `--accuracy 0.0`，两张表**逐字节对拍**：

```
$ diff out_a.txt out_a0.txt
（无输出 —— 两份输出完全相同）
```

逐字念出关键三行（两次都一样）：

```
│ intent_accuracy       │ 1.000 │ 意图识别准确率                   │
│ escalation_rate       │ 0.200 │ 人工升级率（越低越好）           │
⚠ Top bad case category: 门店投诉
```

> "**同一个卷子，一个正常答题的 agent，一个只会说'我不理解'的 agent，拿到了一模一样的分数。**
> 而且——注意看这两张表的**最后一节**：一张 bad case 都没有，`⚠ Top bad case` 这一行**压根没出现**。
> **最差的 agent，拿到了最漂亮的一张成绩单，和一句'没有坏例子'。**
>
> 为什么？因为 `--accuracy` 只决定 mock **回哪句套话**，**它压根不是被测对象**——它是"演员"，不是"考生"。
> 真正的判分口径只认你数据里那几个字段（`escalated` / `adopted` / `handle_time_seconds` ……），
> 而那张 5 行的表里，只有一个字段是真填的。**你用一张只有一个真信号的表，测不出任何关于 agent 的事。**"

这一段必须停 10 秒。然后给三条结论（学员照着抄）：

1. **指标好看 ≠ 系统好。** 好看可能只是"没测到"。
2. **`0.000` 有两种含义**：**全错**，或者**根本没这一列**。（幕 5 会看到第三种：真的一个都没有。）
3. **mock 的任何数字都不能写进作品集**（[`12`](12-附录-术语表与模板库.md) §2.4 的 ⚠ 原话）。mock 是**管道验证器**，不是**效果证明**。真效果要等接入真模型那一跑——而今天我们的任务，是**把这条管子铺直、铺诚实**。

> "所以 G5 ① 为什么是 blocker？因为如果你的评估是'一按就好看'的，它就**永远不会告诉你坏消息**——
> 而 FDE 的价值，恰恰是**第一个知道坏消息的人**。"

**④ 幕 4（23–25.5 min）｜"可复现"长什么样（G5 ①）**

同一条命令连敲 3 次，把三份输出的**关键几行**贴在一起：

```
run 1: intent_accuracy 1.000 ｜ escalation_rate 0.200 ｜ Top bad case: 门店投诉
run 2: intent_accuracy 1.000 ｜ escalation_rate 0.200 ｜ Top bad case: 门店投诉
run 3: intent_accuracy 1.000 ｜ escalation_rate 0.200 ｜ Top bad case: 门店投诉
```

> "**同命令、同数据、同结果——这就是 G5 ① '可复现'的全部含义。**
> 注意：可复现**不是**'结果好'，是'结果不随机'。**一个稳定地难看的分数，比一个忽好忽坏的漂亮分数值钱一百倍**——
> 因为前者能当基线用，后者只能当 PPT 用。
> 顺带说清一件事：mock **天然**可复现（固定种子 0）。等你接过真模型，**同一个问题问两次可能得到不同答案**——
> 那时候'可复现'要靠另外三样东西撑：**固定的测试集、固定的提示词版本、固定的模型版本**。这三样今天写进你的验证记录。"

   碰撞率 0.0321 是全厂最高的 3~7 倍。**如果只看平均分，你永远不会知道要先修它。**

   工单 KPI 表，四行全是 `0.0000`，退出码 0。
   → **工具不会替你检查口径。** G5 ① 之所以是你要自己扛的责任，原因就在这。

> "**这才叫'测到了'**：四个数都有明确对象——4 条样本里 3 条意图对、3 条被采纳、1 条升级、平均 285 秒（人类基线 480 秒）。
> 看 `escalation_rate 0.2500` 和 `avg_handle_time 285` ——这两个数**业务方看得懂**，也**业务方在乎**。
> 这就是课件里那句'**评估指标（意图准确率/采纳率与业务口径）**'的意思：
> **能把技术数字翻译成业务数字的人，才配叫 FDE。**"

### 常见错误与纠偏

| 错误 | 纠偏（讲师/助教用） |
|---|---|

## S4 · 复盘（70–80 min · 10 min）

**本节定位**：把"用数据说话"从个人能力变成**集体肌肉记忆**——助教**当面**扮演反对的业务主管（[`07`](07-实战剧本与案例库.md) §4.2 / §3.4），学员被追问时**禁止讲情怀**。

**一句话目标**（开场念）："接下来我问，你们答。**谁要是说'我们模型很准的'——我当场换角度再问一遍。**"

### 分钟级时间盒

| 分钟 | 动作 | 目的 |
|---|---|---|
| 70–74 | **助教示范一轮**：抽 1 名学员，用 [`07`](07-实战剧本与案例库.md) §3.4 的三问连问 | 让全班看到"追到底"长什么样 |
| 74–78 | **三人一组对练**：1 人演学员，2 人轮流念刁难（每组换 2 轮） | 全员动嘴 |
| 78–80 | 抽 1 组念"最难的那个问题 + 我的回应"；命名反模式收口 | 把错误变成公共资产 |

### 讲稿要点

**① 70–74 min｜助教示范：三条刁难原话（[`07`](07-实战剧本与案例库.md) §3.4 逐字）**

助教**不笑、不寒暄**，直接问（学员须用数据回应，**禁止讲情怀**）：

| # | 助教（反对的业务主管）说 | 合格的回应必须含 | 反面（当场点名） |
|---|---|---|---|
| 1 | **"AI 答错了谁负责？出了舆情你们赔吗？"** | 评估指标 + bad case 率 + **HITL 设计** | "我们模型很准的，放心" |
| 2 | **"你们根本不懂我们业务，先把知识库做好再说。"** | 数据体检结论 + **真实数据原型结果** | 跟对方争辩 |
| 3 | **"预算砍一半，功能一个不能少。"** | 成功标准优先级 + **当场划掉哪个放弃标准** | 全盘答应 |

（另外两条留给对练：**"60% 拦截率太低了，我要 95%"** → 基线对比 + 渐进路线 + 反问成本；**"上一个供应商的 Pilot 做了半年，然后没有然后了"** → 时间盒 ≤90d + 验收清单 + 明确 done）

**扮演纪律（讲师必须提前跟助教对齐，[`07`](07-实战剧本与案例库.md) §3.4 原话）**：

> "**助教必须追到底**——学员一给数字就换角度再问；学员说'不知道'时，追问'**那你准备怎么查、什么时候给答复**'（**诚实 + 行动 = 通过**）。"

**暗号（只在学员说对时松口，[`07`](07-实战剧本与案例库.md) §4.2 原话）**：

> 学员说 **"我们可以在 90 天验收清单里加这一条"** → 助教松口：**"这条我要签字。"**

**② 74–78 min｜三人一组对练**

- 每组 3 人：**1 人当学员，另外 2 人轮流念刁难**，念的人不许自己编——**照着屏幕上的五条念**
- 学员的硬规则（写屏幕上）：
  1. **不许讲情怀**（"我们很有热情""一定会努力"）
  2. **不许裸承诺**（"95% 我们能做"——除非能给出基线与路径）
  3. **说"不知道" = 合法**，但必须补一句 **"我 X 时间前给你答复"**
- 两轮后换人，**保证 3 人都被问过一次**

**③ 78–80 min｜抽组念 + 命名反模式**

抽 1 组，**只念两样东西**：最难的问题 + 我们当时的回应。

| 抓到的模式 | 命名（[`12`](12-附录-术语表与模板库.md) §1.6） | 现场替换 |
|---|---|---|
| "放心，我们很准的" | **No HITL**（假设全自动） | "关键决策留人确认：退款 > 政策线走人工" |
| 被"预算砍半"一问就全答应 | **Scope Creep** | "每加一项，砍一项；我当场划掉 X" |
| "这个演示效果特别好" | **Demo-Debt** | "这是真实脏数据上的结果，难看的部分在这儿" |

### 投屏·板书

- 屏幕五条刁难**原文**（[`07`](07-实战剧本与案例库.md) §3.4），一屏放下，对练全程不切屏

  **① 不许讲情怀 ② 不许裸承诺 ③ "不知道"+时限 = 通过**

### 互动设计

- **助教示范时**，让全班当"裁判"：每人手里举个牌子（或群里打 1/0），判断"刚才这句是用数据还是用情怀"

### 学员动作（现场）

- 在群里按 [`07`](07-实战剧本与案例库.md) §5 格式发一条点评（**只点评同伴，不点评自己**）

### 常见错误与纠偏

| 错误 | 纠偏 |
|---|---|
| 学员被问住后开始道歉 | 打断："**不用道歉，给动作。** 你要说的只有一句：'我什么时候给你答复、怎么查'" |

## S5 · 布置 G5 + 明日预告（80–90 min · 10 min）

**本节定位**：收口 + 交底。念清 G5 三条、命名规范、截止与补交；埋 D6 三个钩子。

**一句话目标**（开场念）："今天收的是**证据**：一条能重跑的命令、三个带动作的坏例、一页敢写拒绝的记录。"

### 分钟级时间盒

| 分钟 | 动作 | 目的 |
|---|---|---|
| 80–84 | **念 G5 三条**（①② blocker / ③ warning）+ 命名规范 + 截止 | 让判据不可含糊 |
| 84–87 | **验证记录模板**（[`12`](12-附录-术语表与模板库.md) §2.6）投屏逐行讲 | ③ 是 warning，但答辩要看 |
| 87–90 | **D6 三个钩子** | 制造明天的注意力缺口 |

### 讲稿要点

**① 80–84 min｜G5 三条 + 命名 + 截止**

- **G5 原文**（[`03`](03-评估体系与通关门禁.md) §3，逐字念）：
  > ① 评估**可复现**（同命令同结果）② bad case Top3 每条含**"下一步动作"** ③ 有一页**"验证记录"**（含被拒绝的需求）
  > —— **①② blocker；③ warning**。
- **点名各自的不通过形态**（学员最需要听的）：
  - **① 不过**：给不出命令 / 给不出测试集 / 换台机器跑不出来
  - **② 不过**：Top3 里有任何一条只写现象不写动作；动作里没有**人、数量、期限**三要素
  - **③ 扣分**：验证记录里**只写"我们接受了 A、B、C"**——**没有一条"我拒绝了什么"**（[`12`](12-附录-术语表与模板库.md) §2.6 原话：**"被拒绝的需求要写进来。答辩评分表里'边界感'一项，看的就是你敢不敢写'我拒绝了什么'。"**）
- **命名 + 提交物清单**（四个文件，一次说清）：

| 提交物 | 文件名 | 对应 G5 |
|---|---|---|
| 评估报告（指标表 + 真信号/默认值标注） | `D5-姓名-评估报告` | ① |
| Bad Case 清单（Top3 × 四要素） | `D5-姓名-BadCase清单` | ② |
| 验证记录（一页） | `D5-姓名-验证记录` | ③ |
| 原型演示（≤2 分钟视频或演示脚本） | `D5-姓名-原型演示.mp4` | 🎯 ① |

- **截止与补交**（与 D4 同规则，复述一遍）：**直播次日 21:30 前**提交；24 小时内补交 = **正常放行（标注"补交通过"）**；逾期 = **延期通过（作品集等级最高 B）**；豁免进证书备注。

**② 84–87 min｜一页验证记录：四行表（[`12`](12-附录-术语表与模板库.md) §2.6）**

投屏这张表，逐行讲怎么填：

| 时间 | 演示/验证对象（角色） | 结果 | 下一步 |
|---|---|---|---|
| D5 上午 | 客服主管（钱锋角色） | 接受 | 纳入 90 天验收清单 |
| D5 上午 | 数据总监（邓琳角色） | 接受（附条件） | 补 PII 处置说明 |
| D5 下午 | 运维负责人 | **拒绝**（理由：无回滚方案） | **不做**，转 D6 讨论 |
| D5 下午 | 业务 VP（罗成角色） | 未决 | 下次评审给答复 |

汇总一行（照抄结构）：**"演示 3 次覆盖 3 类角色；接受 2 项，拒绝 1 项；未决 1 项。"**

> "注意第三行——**'拒绝'那行是这页纸的重点**。它不是'我们没做'，是'**我们决定不做，并写了理由**'。
> 这两者在答辩现场的差别是：**一个叫边界感，一个叫漏项。**"

**③ 87–90 min｜D6 三个钩子**

念 [`05`](05-讲师手册.md) §4 D5 第 3–5 条与 D6 引子（**原话**）：

> 1. （角色扮演收口）"今天你们被反对过一次了。**明天开始，你要为凌晨 2 点值班的人写文档。**"
> 2. "先想一个问题，明天开场我要问：**'你走了以后，谁修？'**"
> 3. "还有一个更难受的问题留给你：**你今天这套东西，半夜三点坏了——修它的人认识它吗？**"

补一句与工具相关的预告（**别破梗，只说现象**）：

> "另外，明天我们会碰到一个今天完全没碰的字母组合：**SLO**。
> 你们今天跑出来的 `escalation_rate 0.2500`、`avg_handle_time 285`，**明天要变成一纸承诺**——
> 承诺里会写清楚'**坏了多久算坏、谁来修、修不好怎么办**'。今天先睡，明天见。"

### 三条路径（学员按自己情况选一条）

| 路径 | 谁选 | 做什么 |
|---|---|---|
| **A 完成** | 大多数人 | 四件产出齐活 + 提交（**别加戏，先交出去**） |
| **B 迁移** | 手里有**已脱敏且经公司同意**的数据 | 把真实业务数据做成 5 行 `test_set.jsonl` 跑一遍；**报告里只写统计与结论，不贴原始样本**；**不得投屏、不得传群、不得进任何第三方工具**（[`11`](11-工具与环境准备.md) §6.1）；录屏前 3 秒自检客户名/PII |
| **C 加练** | 想再挖一层 | ① 把 `--accuracy` 从 0.9 调到 **0.0** 再跑一次，**逐格对比两次表格**，写 100 字说明"为什么 mock 的数字不能进作品集"；② 给你的测试集**补上** `handle_time_seconds` 与 `csat`，观察 `avg_handle_time` 与 `customer_satisfaction` 两行**怎么从默认值变成真信号**。练的是：**一眼分辨真信号与默认值** |

> 路径 C 的第二步特别值钱：**你会亲手看到"同一张表，加上两列字段，两个数字就从假变真"**——
> 这就是"评估设计"这个词的全部含义。

### 完成标准（提交前逐条打钩）

```

☐ 评估报告里每个数字都标了【真信号】或【默认值】，真信号附一行"怎么算的"
☐ Top3 bad case 每条四要素齐全；"下一步动作"三要素：有人做 / 有数量 / 有期限
☐ 一页验证记录四行表填满；至少 1 条"被拒绝的需求"（含理由）
☐ 原型演示 ≤2 分钟，跑在真实数据原型上；无客户名 / 无 PII / 无域名
☐ 全程没有把 mock 的数字当作"效果证明"（措辞自查："验证了管道"而不是"证明了效果"）
☐ 命名：D5-姓名-评估报告 / -BadCase清单 / -验证记录 / -原型演示.mp4
```

### 卡点急救

| 卡在哪 | 怎么救 |
|---|---|
| `FileNotFoundError: ... 'xxx.jsonl'` | 99% 是存成了 **`.jsonl.txt`**（记事本默认存"文本文档"）——把类型改成"**所有类型**"，或存完重命名去掉 `.txt`（[`12`](12-附录-术语表与模板库.md) §2.4 零基础三步） |
| 表格里怎么全是 1.000 / 3.000 / 0.000 | 这是**默认值三兄弟**，不是错误。对照 [`12`](12-附录-术语表与模板库.md) §2.4「读表前必看」逐行划掉，只留真信号。**要看到真信号就填字段**：`adopted` / `escalated` / `handle_time_seconds` / `csat` |
| `intent_accuracy` 恒 `0.000` | 先查**是不是留了 `expected_category`**：**删掉它**（mock 路线）；或改 `--agent mimo`（需要 key，**共享终端不许填**） |
| 想跑 `--agent mimo` 但没 key | `LLM not configured …` + **退出码 2**（拒绝开工，不会静默降级）。课后到个人环境配 key 再试；[`12`](12-附录-术语表与模板库.md) §3.5 有完整记录 |
| `kpi` 跑出来全是 `0.0000` | 两种可能：**① 字段名不匹配**（拿工单 KPI 表对比样本字段：`intent_correct` / `adopted` / `escalated` / `handle_time_seconds`）**② engagement 不存在**（报 `Engagement not found`，退出码 2）。**工具都不会替你把关** |
| 在 `/tmp` 里跑 `kpi` 报 `Engagement not found` | `kpi` 认的是 `.fde_scope/`——**命令从仓库根执行**，样本用绝对路径 |
| 不知道"根因假设"怎么写 | 写一个**明天能被推翻的句子**：不写"模型不行"，写"缺 X 类样本"——推翻它的动作就是"补 X 类样本再跑一次" |
| 录屏老超 2 分钟 | 砍掉开场客套——**只留三样**：跑命令 → 指一个数字 → 说"这证明了什么"。2 分钟够用 |
| "我拒绝的需求写什么？" | 从演练里抄：**拒绝"全自动"**（改 HITL）、**拒绝"95% 拦截率"**（改渐进路线）、**拒绝"砍预算不砍功能"**（改放弃标准）——选你真说过的那一条 |

### 助教值守规则

- **只回答两类问题**：① 规则类（命名 / 截止 / 字段 / 报错 / 数字对不上）② "这条算不算'下一步动作'"
- **不回答**：D6 之后的方案类问题；"我能不能不交 ③"这类豁免请求（**③ 是 warning，交不交自己决定**）
- 每 15 分钟在群里发一次进度提示（"还有 30 / 15 / 5 分钟"）
- 收到提交后**只回一个字**：`✓`（讲评在次日 08:30 门禁榜 + D6 回炉）
- 提交里出现**真实客户名 / PII / 真实 key** → **立即私聊要求撤回重交**，并记录合规日志（[`11`](11-工具与环境准备.md) §6.7）
- 学员问"我这评估算通过吗" → **只回一句**："**① 能重跑吗？② 三条都有动作吗？** 两条都是'是'，就是过。"

### 学员动作

- 45 分钟独立完成（路径 A / B / C 三选一）
- 自评 G5 三条 + 完成标准逐条打钩
- 提交 → 收到 `✓`
- 在群里写 60 秒收获（照 [`07`](07-实战剧本与案例库.md) §5 模板）：
  「**对方最难的那个问题是什么？我用了什么回应？下次我会改什么？**」

### 常见错误与纠偏

| 错误 | 纠偏（助教用） |
|---|---|
| 报告写成"工具输出汇编" | "**工具给你的你都贴了，工具给不了的呢？** 真信号/默认值的判断、Top3 的根因、拒绝的理由——这三样才是你的报告" |
| 把 1.000 当成绩写进结语 | 递「读表前必看」表，**让他自己划掉**，然后问："划掉之后，你手里还剩几个真数字？" |
| Top3 全是同一类（如全是方言） | "合并成一条，再找两条别的——**Top3 是三个不同的烧钱口**" |
| 验证记录只有"接受"，没有"拒绝" | 追问三连（全自动 / 95% 拦截率 / 砍预算不砍功能），逼出一条真的 |
| 21:30 前赶不上 | 别慌：**24 小时内补交 = 正常放行（标注"补交通过"）**——但要**在群里报一句"我补交"**，别静默 |
| 提交里带了真实客户名 | **撤回重交 + 合规日志**，不做例外（[`11`](11-工具与环境准备.md) §6.1 / §6.7） |
