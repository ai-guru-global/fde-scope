# 06 · 学员手册与作业包

> 写给学员：8 天里你只需要盯住这一份文档。
> **每天一张任务卡**：做什么 → 交什么 → 门禁自查 → 卡住找谁。
>
> 判分依据见 [`03-评估体系与通关门禁.md`](03-评估体系与通关门禁.md)｜装环境见 [`11-工具与环境准备.md`](11-工具与环境准备.md)｜全部模板见 [`12-附录-术语表与模板库.md`](12-附录-术语表与模板库.md)
> 课前读物见 [`00-FDE方法论历史与原理.md`](00-FDE方法论历史与原理.md)（**开营前 20–40 分钟**，见 §0.5）

## 0. 先读这 5 句

1. **第 1 天全天 6 小时，第 2–8 天每天约 2.25 小时**（90 分钟直播 + 45 分钟自练），合计**约 22 小时**。排不进去就别报——这门课不靠"抽空看看"过关。
2. **每天交一件产出**，产出里必须有**证据**（命令、文件、截图）——没有证据 = 没交。
3. **门禁制**：当天的产出不过关，就暂时进不了下一关；补交可以，但**留痕**（作品集等级受限）。
4. **练习只用虚构数据**（课程自带）或你自己**已脱敏**的数据；永远不上传真实客户 PII。
5. **鼓励用 AI 助手**——但你得能脱稿讲清自己的关键决策（答辩会抽查）。

## 3. 每日任务卡怎么用

每张卡四件事：**今日产出 → 完成步骤 → 门禁自查 → 提交**。
建议开播前 5 分钟把当天卡打开；直播"布置"环节只念门禁检查项，细则以本卡为准。

**提交截止**：直播次日 21:30（运营催交时间）；次日 08:30 出"门禁通过榜"。
**命名规范**（统一，缺一律打回）：`D<N>-姓名-产出名`，如 `D2-张三-委托单`；
同一产出多文件时加后缀：`D2-张三-委托单-干系人图.png`。

## 4. 每日任务卡

### Day 1 · 入门日

**今日产出（🎯 产出 1）**：迷你链路证据包

- [ ] **课前**：按 §0.5 读 [`00`](00-FDE方法论历史与原理.md) 的 20 分钟版，带一个问题进直播
- [ ] 跑通（逐条复制，**必须在仓库根目录、已激活虚拟环境**）：
      `fde-scope connect --type csv --source examples/quickstart_csv/sample_tickets.csv`
      `fde-scope corpus --input examples/quickstart_csv/sample_tickets.csv --out reports/corpus_report.html`
- [ ] 提交 `reports/corpus_report.html`（在文件管理器里**双击**它即自动用浏览器打开；
      提交文件本身或报告首页截图均可。打不开先查 `11` §3.2）
- [ ] 写 3 行白话解释："我刚才做了什么、为什么要先看数据、报告里最重要的数字是哪个"
- [ ] 先种案例数据：`python examples/seed_mock_engagements.py`（幂等，重复跑安全）
      再 `fde-scope web` → 打开「**星澜科技（Adnova）**」→ 存好**红色 blocker** 那页的截图
      （空仓库的控制台只有"创建一个 engagement"的提示，**没有 blocker**——所以这一步不能跳）

**门禁自查 G1**：命令真跑过（报告文件真实存在）｜能用自己的话解释｜报告数字与实际一致。
**常见坑**：命令跑在错误目录（应在仓库根目录）｜报告路径看错（在 `reports/` 下）。
**卡住**：先查 `11` 第 3 节排查表 → 再群内提问（用第 7 节的四要素模板）。
> 今天**不需要**背 `00` 里的任何年份与数字——那是速查页，不是考点。

### Day 2 · 定边界

**今日产出（🎯 产出 2）**：客户委托单（≤1 页）

- [ ] 客户画像：行业、规模、谁付钱、现在怎么干活、痛在哪
- [ ] 干系人地图：≥2 位发起人 + 一线使用者 + IT/安全把关人，标注每人"在乎什么"
- [ ] 成功标准 ≥3 条：全部可度量（有数字 + 时间），客户**自己能验收**
- [ ] 时间盒：≤14 天集成 / ≤90 天上线 / ≤120 天交接
- [ ] 放弃标准：什么情况下该说"这个不该做"
- [ ] 用 `07` 的客户简报，或替换成你自己的（脱敏）场景

**门禁自查 G2**：成功标准 ≥3 条全可度量（禁"提升体验"类形容词）｜≥2 位发起人｜有放弃标准｜≤1 页（超 2 页直接打回）。
**常见坑**：成功标准写得只有工程师能测（验收主体必须是客户）｜发起人只有一位（想想"他明天离职项目还活着吗"）。

---

### Day 3 · 接数据

**今日产出（🎯 产出 3）**：数据体检报告

- [ ] 先猜后看：写下"我猜这份数据有几成能用"，再跑
      `fde-scope connect --type csv --source examples/quickstart_csv/sample_tickets.csv` 对照
      （A/B 两组共用此文件起步；工业补充数据见 `examples/quickstart_manufacturing/`）
- [ ] 概况：条数、来源、采集方式、时间范围
- [ ] 字段表：字段名 / 类型 / 缺失率 / 异常值 / 备注
- [ ] PII 清单：哪些必须脱敏、哪些根本别拿
- [ ] 覆盖度：类别分布 Top/Bottom，指认长尾盲区
- [ ] 结论一句话：**能做 / 不能做 / 有条件能做**（写"待定" = 未达）

**门禁自查 G3**：字段表含类型与缺失率｜PII 清单带处置建议｜明确结论｜≥3 条质量风险。
**常见坑**：只列字段不判风险｜结论不敢下（犹豫就写条件："若能补齐 X 字段则能做"）。

---

### Day 4 · 造语料

**今日产出（🎯 产出 4）**：语料报告 + 客户话术

- [ ] 跑 `corpus` 生成报告；摘录关键数字：原始 N → 可用 M（去重 X、质量门淘汰 Y）
- [ ] 覆盖度：盲区几个、补盲策略是什么（每条合成样本有缺口理由）
- [ ] 写**客户话术 ≤200 字**：向非技术客户说明"能用多少 / 补了什么 / 为什么可信"
- [ ] 诚实标注：合成数据比例与来源（`synthesize:llm` 或规则路径）
- [ ] （可选）有 key 时对比 `--llm` 路径与规则路径

**门禁自查 G4**：报告数字与实际运行一致｜有盲区与补盲说明｜话术**零术语**（出现"语料/覆盖度/合成"即未达）｜合成比例如实标注。
**常见坑**：用合成量掩盖真实缺口｜话术里冒术语（想想怎么跟老板讲"淘米"）。

### Day 5 · 验证与评估

**今日产出（🎯 产出 5）**：原型证据 + 评估结果 + Top3 bad case + 一页验证记录

- [ ] 先造测试集：把 [`12`](12-附录-术语表与模板库.md) §2.4 的模板复制成 `test_set.jsonl`（一行一条 JSON；
      不会存文件？看 §2.4 的"零基础三步"框），先填 5 行跑通再扩到 ≥200 条；
      **首次 `--agent mock` 跑通时先删掉每行的 `expected_category`**
      （否则 `intent_accuracy` 恒为 0.000——这是子串判分的设计，不是 bug，原因见 `12` §2.4）
- [ ] 跑 `fde-scope eval --agent mock --test-set test_set.jsonl`，截取主指标 + 1 个业务口径指标
- [ ] 准备一个可演示的原型（命令输出截图，或 `fde-scope web` demo 录像 ≤2 min）
- [ ] 从 bad case 里挑 Top3：每条写"现象 → 根因假设 → 下一步动作 → 预计改善"
- [ ] 一页验证记录：向谁演示了、对方提了什么、接受/拒绝了什么（拒绝的要写理由）

**门禁自查 G5**：同命令同结果可复现｜bad case 每条有"下一步动作"（只描述现象 = 未达）｜有验证记录（含被拒绝需求）。
**常见坑**：用策展过的漂亮数据（= Demo 债，直接退回）｜只贴平均分不挖坏例子。

### Day 6 · 运维化

**今日产出（🎯 产出 6）**：SLO 卡 + Runbook + 值班交接卡

- [ ] SLO 卡：3 条 SLO（目标值 + 测量方式）+ 错误预算 + 告警路由（谁/渠道/多久响应）
- [ ] Runbook：5 类事件（服务不可用 / 指标暴跌 / 数据异常 / 权限配额 / 上游依赖挂），每类四段：判断信号 → 处置步骤 → **回滚步骤** → 升级路径
- [ ] 值班交接卡：当前状态 / 待办 / 已知风险 / 联系人
- [ ] 自查门禁：`fde-scope gate check <你的档案id>` 看 `slo` 关到底在检查什么
      （id 用 `COLUMNS=200 fde-scope engage list` 查；不加 `COLUMNS` 会被截断成 `eng-xxx-t…`）
- [ ] 找一位同学做"**凌晨 2 点盲测**"：他按你的文档念，能处理完才算过

**门禁自查 G6**：Runbook 每类事件有回滚步骤｜SLO 含错误预算｜告警路由明确｜盲测通过。
**常见坑**：写成了"说明书"不是"操作步骤"（每步都得能照着敲）｜忘了写回滚。

### Day 7 · 交接与沉淀

**今日产出（🎯 产出 7）**：交接包四件套 + 技能卡 + 退场计划

- [ ] 装配交接包：`fde-scope handoff <你的档案id> --accept`
- [ ] 交接包内容：Runbook + 评估报告 + SLO 卡 + 培训材料（题纲即可）
- [ ] 验收清单：谁验收、验收标准、签字人（逐条列出）
- [ ] 技能卡 1 张：`fde-scope skill add --title "<标题>" --category methodology --body "<正文>"`
      内容：场景 → 问题 → 做法 → 证据 → **适用边界**（什么情况下不适用）；确认无误后 `fde-scope skill publish <skill-id>`
- [ ] 退场计划：交接后 30/60 天支持安排 + **终止条件**
- [ ] 答辩式演练：接受"客户运维负责人"的三个刁难问题（剧本见 `07`）

**门禁自查 G7**：四件套齐全｜验收清单含签字人｜技能卡含适用边界｜退场计划有终止条件。
**常见坑**：交接包是给客户的、不是给自己的（客户不打电话能活几天？）｜技能卡写成流水账。

### Day 8 · 变现日

**今日产出（🎯 产出 8）**：作品集三套包装 + 结营答辩

- [ ] 作品集索引页：8 件产出的名称 / 日期 / 证据链接 / 一句话价值

## 7. 求助路径（三级，先自助再找人）

```
Level 0 · 自助
  ├─ 装环境报错     → 11 第 3 节故障排查表
  ├─ 要模板         → 12 模板库（复制即用）
  ├─ 概念不懂       → 12 术语表 + 当天录播回放（2 倍速重看"讲与演"）
  └─ 命令报错       → 逐字比对 02 的任务卡命令（90% 是路径或拼写）

Level 1 · 同学（结对伙伴 + 群）
  └─ 群内提问须带四要素（见下方模板）；同学能答的先答，答对有互助分

Level 2 · 助教（19:00–20:00 答疑窗口）
  └─ @助教 + 四要素；非窗口期留言，值班助教次日 12:00 前回复

Level 3 · 讲师（私聊，仅限）
  └─ 豁免申请 / 严重掉队 / 数据合规疑问 / 想换练习场景
```

## 8. 学习方法（怎么学最快）

| 方法 | 怎么用 | 依据 |
|---|---|---|
| **费曼复述** | 每天复盘环节用 3 句话讲给同桌；讲不清 = 没学懂 | 输出倒逼输入 |
| **回炉** | 每天开播 10 分钟抽考昨日 3 个概念；别只当听众 | 间隔重复 |
| **结对互评** | 强弱搭配，每天交换 1 次产出，**必须找出对方 1 个问题** | 社会学习 |
| **证据文件夹** | 从 D1 开始建 `证据/` 文件夹，随手存命令与截图 | D8 作品集直接取用 |
| **先猜后看** | 看数据/看指标前先写下预期，再对照 | 制造认知冲突 |

**别做的事**：攒到周末补所有作业（记忆曲线已凉）｜抄模板不改（答辩必露）｜用真实客户数据练（红线）。

## 9. 用 AI 助手的开工模板（提示词包）

> 课程鼓励用 AI——这本身就是 FDE 的工作方式。关键约束：**产出要能脱稿讲、数字要自己跑过、AI 参与要标注。**

| 场景 | 提示词模板 |
|---|---|
| 改成功标准 | "以下是我写的成功标准，客户是<角色>。请逐条指出哪些无法被客户自己验收，改写成含数字与时间的版本，并说明改动理由：<原文>" |
| 翻译成客户话术 | "把下面这段技术说明改写成 200 字以内的白话，读者是不懂技术的<客户角色>，不准出现'语料/覆盖度/合成'等词：<原文>" |
| 挖 bad case 根因 | "这是评估失败案例<粘贴>。给出 3 个根因假设，每个附一个可以在 10 分钟内完成的验证动作。" |
| 写 Runbook 初稿 | "为<场景>写运行手册：5 类事件，每类按'判断信号→处置→回滚→升级'四段。要求每步可被值班新人照着执行。" |
| 角色扮演陪练 | "你现在扮演一位反对上 AI 系统的业务主管，对我提 5 个尖锐问题，每次只问一个，等我回答后再追问。" |

**使用纪律**：AI 给的内容你自己跑过/核过才能进产出；末尾标注"本件部分内容由 AI 辅助生成"。

## 10. FAQ（学员版）

| 问 | 答 |
|---|---|
| 少上一天直播行不行？ | 行，录播 24h 内补看并补交当天门禁；连续 2 天未打卡会触发三级干预（班主任会找你）。 |
| 装环境一直报错怎么办？ | 先查 `11` 第 3 节；仍不行进"环境急诊室"分组，助教 1v1；最差情况助教共享屏代跑、你口头指挥——照样算你完成。 |
| 没有 API key 能学吗？ | 能。全链路零 key 可跑（规则模式），LLM 只是可选加速器；D4 会演示有/无 key 的差别与失败回退。 |
| 能拿公司真实项目练吗？ | **可以，但必须先脱敏并经你的公司同意**；真实客户名与 PII 一律不进群、不上传。拿不准就问讲师。 |
| 我平时用的 Qoder / Trae / 豆包工作 这些，跟课程冲突吗？ | 不冲突，**不要求换工具**。课程只叠"流程与门禁层"；编码、写文档继续用你顺手的（`01` §6.4）。 |
| 我的指标很差是不是做错了？ | 指标是地图不是成绩单。把最难看的那个数字翻译成"1 个 bad case + 1 个下一步动作"就对了。 |
| 能改案例吗？ | 能。`07` 的案例允许替换成你熟悉的行业场景，但四区结构与门禁不变。 |
| 全用 AI 生成的行不行？ | 行。答辩会请你脱稿讲 3 分钟，讲不清的判定为未达——这是课程唯一的"防伪"。 |
| 证书怎么拿？ | 过 G8 结业门即可（G1–G7 至少 6 关 + 索引完整 + 答辩完成）；A/B/C 级判定见 `03` 第 6 节。 |
