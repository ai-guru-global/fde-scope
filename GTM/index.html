十个门禁，全部是可执行代码

不是清单条目。Gate.check(ctx) 返回通过/阻断/警告，advance 不干净就拒绝。其中七个只存在于工厂场景。

互锁面板数字键 1–0 直达门禁
1site_survey现场位置必填；资产为空或多班次无网络 → 警告。
2success_criteria书面标准 + ≥2 发起人；发起人无指标 → 警告。
3functional_safetyPL/SIL 达标；ISO 10218 评估；危害分析强制（阻断项）。
4fat_satFAT 与 SAT 均通过且分别签核。
5conformity高风险 ⇒ CE 标志 + 技术构造文件 + 危害分析。
6works_council有员工代表时须劳资共决签核。
7air_gap离线部署形态在接入时定论，杜绝事后外联。
8shift_handover多班次现场须有数字交接日志 + 分班次 runbook。
9sloSLO/SLA + 错误预算 + 告警路由；缺路由 → 警告。
0handoff_signoff交接包齐备（runbook/评估/SLO/培训）且客户签收；缺适用边界（G7③）/ 终止条件（G7④）→ 警告，不阻断。

产品

功能清单

  • 18 阶段 SOP — 门禁是代码 Gate.check()，不是检查清单
  • 2 套场景 — 工业门禁：FAT/SAT · ISO 13849 · CE/EU-AI-Act · BetrVG §87 · 气隙 · 换班
  • 10 个数据连接器 — CSV/MySQL/OPC UA 真实 · MQTT-Sparkplug/MES JSONL · Documents 解析延迟导入
  • 语料锻造 — 脱敏→质量门→覆盖度→缺口检测→补盲区合成
  • 评估 + 工业 KPI — OEE / MTBF / 抓取成功率 / 碰撞率
  • 技能库 — AgentScope 与 QwenPaw 双格式导出
  • 本体语义层 — fde-core + ISA-95 overlay · SKOS 概念体系驱动语料覆盖与技能检索 · ONTO-* 错误码校验
  • 部署三支柱 — Agent 装配 · 权限上下文 · 沙箱 workspace
  • 交接 + 飞轮 — 无 key 全走规则路径，失败自动回退

架构

架构清单

  • 核心层 — 零顶层 agentscope 依赖：无 key、无 Docker 五分钟全绿
  • deploy/ — 三支柱运行时组装，optional extra
  • connectors/documents.py — PDF/Word/Excel/PPT 解析延迟用 agentscope.rag
  • 横切层 — 唯一 LLM 出口 llm.py；本体 TBox/ABox/SKOS 原子落盘；data_root() 四级解析
  • 4 个界面 — CLI · Web 控制台 32 路由 · PawApp 18 路由 · macOS DMG 双击即用
  • 证据模型 — Structurizr DSL + DOT 为事实源，Mermaid 沉淀可读图

最佳实践

六条不变式

  • 门禁实时重评 — 每次 advance 重评门禁，过期 passed 不放行
  • 服务端生成 ID — 外部输入永远不能指定记录 ID
  • 密钥仅存环境变量 — 密钥只走环境变量，绝不落 manifest/报告/日志
  • 原子写入 — 所有落盘记录经 fsutil.atomic_write_text
  • 仅规则授权 — 唯一权限通道；未匹配工具 DEFAULT→ASK · DONT_ASK→DENY
  • 实测 AgentScope 窗口 — >=2.0.4.post1,<3 逐版本实测，契约测试钉住引用

验证来源：CI 全绿套件 · 契约测试 tests/test_architecture_guard.py · 证据模型 docs/architecture-model/architecture-map.md
