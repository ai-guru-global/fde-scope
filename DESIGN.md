# FDE Scope Enterprise Visual Design System

One design system for all three product surfaces. Locked 2026-09-02 via a Hallmark
multi-page redesign run.

| Surface | File | Page type |
|---|---|---|
| GTM 官网 | `GTM/index.html` (published to Meoo CDN) | marketing |
| FDE Skills 手册库门户 | `docs/skills-catalog/site/index.html` (generated by `scripts/build_catalog_site.py`) | content |
| Web 控制台 | `fde_scope/web/app.py` (`/` overview + `/console`) | app |
| Android 客户端壳 | `android/` (`MainActivity.java`, `res/values[-night]/colors.xml`) | native chrome |

Enterprise-light convention: light is the default everywhere; the web console keeps
an explicit `html[data-theme="dark"]` override (relaxed from the earlier Graphite
token set, same hue family). Static pages (GTM, portal) stay light-only. The Android
shell mirrors the console tokens as exact sRGB resources: `values/colors.xml` (light)
and `values-night/colors.xml` (dark, follows system night mode); radius ladder 6/7/10,
ripple pressed states use `panel2` (ghost) and `accent-2` (primary).

## Cross-site navigation (mandatory keep)

- GTM 页脚 nav + portal topbar link each other (`../docs/skills-catalog/site/index.html` ↔ GTM repo path; the published GTM lives at `https://npwgp04gxyp1.meoo.fun`).
- Web console topbar has 「GTM 官网」(Meoo URL) and 「技能手册库」(repo-relative path, new tab) links on both `/` and `/console`.

## Genre & Macrostructure

- Genre: **modern-minimal** (restrained, enterprise-grade; no toy/neo-brutalist chrome).
- Marketing (GTM): board console — a full-bleed "live gate board" hero (lanes + T-cards + readout) followed by evidence sections (shift log, gate interlock, work orders, ledger, shipped console, tool crib, ship list). Keep this IA and all interactive logic.
- Content (portal): directory listing with search, zone filter, per-page cards.
- App (console): overview `/` = Long Document; `/console` = Workbench.
- Diversification is **inverted**: all three surfaces share the system; pages differ only in macrostructure within their family.

## Theming

- Light is the default (`:root`); dark is an explicit override on `html[data-theme="dark"]` (console only; no `prefers-color-scheme` media query, resolved by the inline head script via `localStorage['fde-theme']` → `matchMedia`).
- Theme toggle (console): 32px ghost button in topbar (sun/moon sprite icons).

## Typography

- GTM / portal: **Public Sans** (self-hosted woff2; display = weight 800, body = 400/600/700) + **Spline Sans Mono** (self-hosted; readouts, commands, metadata) + `Noto Sans SC` / system CJK fallback.
- Console: zero external fonts (`-apple-system` stack; mono `ui-monospace` stack).
- Display (GTM hero): `clamp(2.4rem, 5vw, 4.6rem)`, weight 800, letter-spacing -0.02em, roman (never italic).
- Section h2: 19–22px / 650–700. Body: 14–16px. Mono UI labels: 11px uppercase where semantically a key.

## Spacing, radius, borders

- Cards 14–24px padding; section top spacing 44px (GTM sections 56–96px, marketing rhythm); grid gap 10px.
- Radius ladder: 6 (small controls) · 7 (inputs/buttons) · 8 (pill) · 9 (cards) · 10 (stat tiles, dialogs, GTM board frame).
- All cards: 1px solid `var(--border)`, subtle shadow allowed on marketing surfaces (`0 18px 40px -20px oklch(0.3 0.02 255 / 0.35)`); console cards use no shadows except dialog/toast.

## Motion

- Only `color`, `border-color`, `background-color`, `opacity` transitions at **120–160ms**. No `transform` on hover.
- Entrance reveals: GTM keeps its mechanical slot-in (`slot-in`, `thud` — opacity + slight translate/rotate, both from `prefers-reduced-motion: reduce` kills all).
- Reduced-motion fallback: opacity-only crossfade ≤ 150ms; `scroll-behavior:auto`.
- Console: entrance animations none.

## Microinteractions stance

- Silent success; toasts only for destructive/confirmable actions (console toast kinds: ok/warn/bad, left dot + border tint).
- Hover delay 800ms · focus delay 0ms.
- Focus: `:focus-visible` → `var(--accent)` outline + halo (`0 0 0 3px var(--accent-dim)`); never animate the ring.
- Copy buttons (GTM crib): COPY → COPIED ✓ inline label.

## CTA voice

- Primary: accent fill, `--accent-ink` text, radius 7–8px, verb-first copy, no exclamation marks.
- Secondary: ghost/outline (`--border`), same radius, `--fg` text.
- GTM hero push-button keeps its press-depth microinteraction (translateY + shadow collapse) but in accent blue, not safety orange.

## Semantic color discipline

- `--good/--warn/--bad` appear only as status dots (7–10px), state lamps, or text on gate/phase states. Never as large fills or banners.
- Status pill text stays `--muted`/`--fg`; the dot carries semantics.

## Iconography

- Console: single inline SVG sprite (`_ICON_SPRITE`, 16×16, stroke 1.5 round).
- GTM / portal: inline SVG paths, `stroke:currentColor; fill:none`, stroke-width 1.8 (GTM retains its inline glyph set).
- No emoji as chrome. Emoji only where content (e.g. 「🤖 Agent 部署」 label).

## What all surfaces MUST share

- The engineering-blue accent and its placement (≤ 5 % per viewport).
- Hairline border language, radius ladder, 120–160ms motion.
- Enterprise copy voice: declarative, numbers only when real.

## Per-page family rules

- Marketing (GTM): MAY use the live-board enrichment (T-cards, lamps, readout) — it is the product's signature.
- Content (portal): typography-led directory, hairline cards, sticky search topbar.
- App (console): function carries the page; no marketing enrichment.
