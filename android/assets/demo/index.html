10 个可执行合规门禁（Gate · 工业 overlay 叠加层）

02

门禁（Gate）是谓词，不是清单：清单记录"曾经查过"，随现实漂移单向腐化；门禁在每次推进时重新评估，过期 passed（通过）不作数。--force 只豁免拦截、照常评估留痕，例外进入审计日志。

架构清单 · 四层 + 横切

05

证据化建模见 docs/architecture-model/。

UI 层
CLI（Typer，全延迟导入）· Web 控制台（27 路由）· QwenPaw PawApp（18 路由 /api/fde-scope）· macOS App（DMG 安装镜像，双击即用，即本控制台）。
SOP 层
engagement/：18 阶段 · 4 大 Zone · 10 个可执行门禁（gate，advance 实时重评估）+ handoff（移交）；profiles/：ticket · manufacturing 场景选择器。
能力层
connectors · corpus · deploy · eval · flywheel · integrations · skills —— 核心数据管线，规则为底、大模型（LLM）可选增强。
横切层
llm.py（唯一 LLM 出口，失败回退规则路径）· config.py · templates/（Jinja 报告与 runbook）· paths.py（data_root 唯一路径解析）。
文件事实源
零数据库：.fde_scope/（engagements · skills · uploads）+ reports/；一律经 fsutil.atomic_write_text 原子写。
外部依赖（全可选）
AgentScope 2.0.x（可选依赖组 extra，实测窗口 >=2.0.4.post1,<3；deploy 三支柱 + documents 延迟导入）· MiMo 大模型（LLM，凭据仅环境变量）· QwenPaw 宿主。

工程最佳实践 · 六条不变式

06

AGENTS.md 契约，由架构守护测试钉住。

1Gate 实时重评估
advance() 每次重评当前阶段全部门禁（gate），过期通过不作数；强推也评估留痕。禁止缓存/短路。
2ID 服务端生成
SkillRecord.id / EngagementContext.id 由所属服务分配，外部输入永远不能指定。
3凭据只走环境变量
API key 不落 manifest / 报告 / engagement JSON / 日志。
4原子写盘
一切用户状态经 fsutil.atomic_write_text（临时文件 + os.replace），禁止裸 write_text。
5规则授权是唯一通道
build_toolkit 不打 is_read_only（上游 ≥2.0.5 read-only 先放行）；未匹配工具按模式回退 DEFAULT→ASK / DONT_ASK→DENY。
6实测版本窗口
pyproject 与 docs 逐字引用同一 agentscope specifier，放宽前逐版本真库跑测。

验证锚点：make test · pytest tests/test_architecture_guard.py（6 项契约）· pytest -m agentscope（真库运行时）· ruff check + format --check · 架构证据模型 docs/architecture-model/architecture-map.md

快速上手

08
CLI 命令行
# 安装（核心层零依赖）
pip install -e ".[dev]"

# 启动制造业 engagement（驻场项目）
fde-scope engage init --customer aurora-motors --profile manufacturing

# 推进 SOP（门禁拦截）
fde-scope engage advance <id>
fde-scope gate check <id> --gate fat_sat

# 语料锻造 + KPI
fde-scope corpus --input alarm.jsonl --out r.html
fde-scope kpi <id> --samples station.jsonl

# 生成移交包
fde-scope handoff <id> --accept
Web 界面
# 启动交互控制台
pip install -e ".[web]"
fde-scope web
